## 一、电缸概况（P5-6）

### 指示灯定义 ⭐ 售后快速判态

| 状态 | 指示灯 |
|---|---|
| 未回零 | 红灯闪烁，其他灯不亮 |
| 回零完成 | **蓝灯常亮**（进入可操作状态） |
| 收到命令 | 蓝灯闪烁一次（执行命令中） |
| 堵转 | **绿灯常亮**，其他灯不亮 |

### 线序定义（P5-6，8 芯 + 编织线）

| 序号 | 颜色 | 定义 |
|---|---|---|
| 1 | 绿 | 485A（T/R+，通讯正） |
| 2 | 橙 | 485B（T/R-，**通讯负**）（C026：手册原文标"正"是笔误） |
| 3 | 黑 | Output1（IO 数字输出 1） |
| 4 | 黄 | Output2（IO 数字输出 2） |
| 5 | 红 | 24V（直流正极） |
| 6 | 棕 | Input2（IO 数字输入 2） |
| 7 | 白 | Input1（IO 数字输入 1） |
| 8 | 蓝 | GND（直流负极） |
| 外壳 | 编织线 | PE（外壳接地） |

> ⚠️ 线标丢失/脱落时**必须联系大寰配合确认**，接错线序导致损坏后果自负。

## 二、Modbus-RTU 控制（P7-41）

### 默认通讯配置（P12）

| 项 | 默认值 |
|---|---|
| ID | 1 |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |

### 两套寄存器协议 ⭐ 关键

电缸手册包含**两套 Modbus 寄存器协议**（目录 5.1/5.2 分别给两种控制流程）：

| 协议 | 特征 | 定位 |
|---|---|---|
| **2.3 直接寄存器模式（0x0100 起）** | 每个功能一个寄存器，赋值即执行（位置/力/速度/推压段），无控制字 | 简单直观，与电爪手册同源 |
| **2.4 控制字模式（0x1600 起）** | 目标位置 + 0x1605 控制字（bit 位操作：使能/定位标志/回零上升沿触发） | **推荐使用**（C025：更符合编程习惯，接近伺服控制） |

> ✅ 两套协议在**电缸所有版本都并存**（C025），非新旧版本二选一；**推荐用 0x1600**。

### 2.3 直接寄存器模式 基础控制地址表（P13-14）

| 功能 | 地址 | 写入说明 |
|---|---|---|
| 电缸回零 | 0x0100 | 写入 0x01 回零位（找单向位置） |
| 推压力值 | 0x0101 | 1-100 百分比 |
| 推压段长度 | 0x0102 | 0-65535，单位 0.01mm |
| 目标位置 | 0x0103 | 0-65535，单位 0.01mm |
| 最大速度 | 0x0104 | 1-100 百分比 |
| 加/减速度 | 0x0105 | 1-100 百分比 |
| 相对位置 | 0x0106 | -32767~32767，单位 0.01mm |
| 点动 JOG | 0x0107 | -1 反向 / 0 停止 / 1 正向 |

### 2.3 直接寄存器模式 反馈地址表（P14）

| 功能 | 地址 | 读取 |
|---|---|---|
| 回零状态 | 0x0200 | 0 未回零 / 1 回零成功 / 2 回零中 |
| 运行状态 | 0x0201 | 0 运动中 / 1 到达位置 / 2 堵转 |
| 位置反馈 | 0x0202 | 实时位置，单位 0.01mm |
| 电流反馈 | 0x0204 | 实时电流 |

### 2.3 参数配置地址表（P14-15）

| 功能 | 地址 | 说明 |
|---|---|---|
| 写入保存 | 0x0300 | 0 默认 / 1 写 Flash（配置完必须执行） |
| 回零方向 | 0x0301 | 0 前进 / 1 后退（默认 1 后退） |
| 设备 ID | 0x0302 | 1-247（默认 1） |
| 波特率 | 0x0303 | 0-5：115200/57600/38400/19200/9600/4800 |
| 停止位 | 0x0304 | 0=1 停止位 / 1=2 停止位 |
| 校验位 | 0x0305 | 0 无 / 1 奇 / 2 偶 |
| 行程限制 | 0x0306 | 单位 0.01mm |
| 原点偏置 | 0x0308 | 单位 0.01mm |
| 推压速度 | 0x0309 | 1-100 百分比（默认 20） |
| 推压方向 | 0x030A | 0 正向 / 1 反向 / 2 双向 |
| IO 参数测试 | 0x0400 | 1/2/3/4 直接控制 4 组 IO |
| IO 模式开关 | 0x0402 | 0 关闭 / 1 开启 |
| IO 参数配置 | 0x0405-0x0418 | 4 组 ×（位置/加速度/速度/推压段/推压力） |
| 上电自动回零 | 0x0504 | 0 关闭 / 1 开启（配合 IO 模式） |

### 2.4 控制字模式 地址表（P33-36）⭐

**基础控制**：

| 功能 | 地址 | 说明 |
|---|---|---|
| 目标位置 | 0x1600 | 0-65535，单位 0.01mm |
| 推压段行程 | 0x1601 | PUSH=1 时有效，单位 0.01mm |
| 最大速度 | 0x1602 | 单位 0.01mm/s（注意：非百分比） |
| 加/减速度 | 0x1603 | 1-100 百分比 |
| 推压力 | 0x1604 | 1-100 百分比 |

**控制字 0x1605（bit 位）**：

| Bit | 功能 |
|---|---|
| Bit15 | 抱闸控制（0 无动作 / 1 强制松抱闸） |
| Bit14 | 绝对/相对位置选择（0 绝对 / 1 增量） |
| Bit13 | 推压方向（0 正向 / 1 反向） |
| Bit12 | 推压运动（0 位置 / 1 推压） |
| Bit9 / Bit8 | JOG+ / JOG- |
| Bit5 | 电机使能（0 失能 / 1 使能） |
| Bit4 | 复位（上升沿） |
| Bit3 | 暂停 |
| Bit1 | 回零（上升沿执行） |
| Bit0 | 定位标志（上升沿执行动作） |

**状态字 0x1611（bit 位）**：

| Bit | 功能 |
|---|---|
| Bit15 | 急停状态（1 急停） |
| Bit14 | 电源状态（1 准备好） |
| Bit10 | 电机使能状态 |
| Bit9 | 报警状态（1 有报警） |
| Bit8 | 运动状态（1 运动中） |
| Bit6 | 回零状态（1 回零完成） |
| Bit5 | 到位状态（1 到位） |

**反馈**：位置 0x160C（0.01mm）/ 电流 0x160D（mA）/ 速度 0x160E（0.01mm/s）/ 报警代码 0x160F。

### 常用操作速查（控制字模式，P36-41）

- **回零**：先给 0x1605 Bit1 置 0 + 电机使能 → 再置 Bit1 触发（上升沿）
- **失能/使能**：0x1605 Bit5；使能写 `...20...`（Bit5=1），失能写 `...00...`
- **绝对定位**：写 0x1600 位置 + 0x1605 Bit14=0（绝对）
- **相对定位**：写 0x1600 + 0x1605 Bit14=1（增量）
- **推压运动**：写 0x1601 推压段 + 0x1605 Bit12=1（推压）
- **清除报警**：0x1605 Bit4（上升沿）

## 三、IO 控制（P42-44）

### IO 模式配置步骤
1. 打开 IO 模式 → 选直接模式 → 点读取
2. 配置 4 组 IO 参数（位置/加减速度/速度/推压段/推压力）
3. 点保存（写 Flash）→ 重启
4. 重启后回零/初始化 → 设 0x0402=1 即切换 IO 模式成功

### INPUT 状态映射（NPN 型默认，2 线 4 状态）

| INPUT1 | INPUT2 | 执行 |
|---|---|---|
| 高阻(断开) | 高阻(断开) | 第 1 组状态 |
| 0V | 高阻 | 第 2 组状态 |
| 高阻 | 0V | 第 3 组状态 |
| 0V | 0V | 第 4 组状态 |

### OUTPUT 反馈（电缸 3 状态）

| OUTPUT1 | OUTPUT2 | 状态 |
|---|---|---|
| 高阻 | 高阻 | 运动中 |
| 0V | 高阻 | 到位（未夹物体） |
| 高阻 | 0V | 堵转 |

> ⚠️ IO 模式打开后，软件上 485 模式受限无法控制，但 485 通讯功能不受影响；IO 与 485 可同时控制，遵循"先发先响应"。

## 四、报警信息（P51-52）⭐ 售后速查

> ⚠️ **本报警表 = 内驱 & 485 外驱版本的报警表**（C024）。**SAC-N2 伺服驱动器（外置伺服型）的故障码表是另一套**，待 Fly 用 Excel 补充（[[corrections]] C003），二者不要混用。
> ⚠️ **报警码以"报警代码（HEX）"列为准**（C027）：真正的十六进制报警码是 0x80/0x82/0x83/…；手册里 ALM_DO 列（0x01/0x02…）不需要参考。

| 报警码(HEX) | 报警级别 | 名称 | 触发条件 |
|---|---|---|---|
| 0x80 | 动作解除 | 伺服 OFF 时移动指令 | 通讯模式：没使能就发运动指令；脉冲模式：没使能就收超 10 脉冲 |
| 0x82 | 动作解除 | 回零未完成时的位置移动指令 | 通讯模式：无该报警；脉冲模式：没回零就收超 10 脉冲 |
| 0x83 | 动作解除 | 回零未完成时的数值指令 | 通讯模式：没回零就发运动指令；脉冲模式：无该报警 |
| 0x84 | 动作解除 | 回零执行中的移动指令 | 通讯模式：回零中发运动指令；脉冲模式：回零中收超 10 脉冲 |
| 0x90 | 动作解除 | 伺服 ON 时的软件复位 | 复位时电机还在使能 |
| 0xBE | 动作解除 | 回零超时 | 回零开始运动 20S 没碰到堵转点 |
| 0xC0 | 动作解除 | 实际速度过快 | 实际速度 >4000 转持续 200ms |
| 0xC9 | 动作解除 | 过电压 | 母线电压 >30V 持续一段时间 |
| 0xCB | 动作解除 | 电流传感器偏移调整异常 | 初始化采电压在 1.65V 的 10% 外（相电流采样电路异常） |
| 0xD5 | 动作解除 | 回零未完成时偏差计数器溢出 | 回零中非堵转，位置偏差 >半圈保持 1S |
| 0xD8 | 动作解除 | 偏差溢出 | 非推压段位置偏差 >4 圈保持 500ms（电子齿轮比设置不合理会触发） |
| 0xD9 | 动作解除 | 行程软限超限 | 回零完成使能下，当前位置超限位保持 1S |
| 0xE5 | 重启清除 | 编码器接收错误 | 编码器线断开持续 500ms 以上 |
| 0xF6 | 动作解除 | 欠电压 | 母线电压 <12V 持续一段时间 |
| 0x86 | 重启清除 | 脉冲串输入有效时的移动 | 通讯模式：无该报警；脉冲模式：串行通信更新了驱动轴目标位置 |
| 0xF7 | 动作解除 | 堵转 | 非推压段堵转超 5S |
| 0xF8 | 动作解除 | STO 急停中 | 驱动电源断线 |
| 0xA3 | 动作解除 | 位置指令信息数据异常 | 收到超限位的位置信息 |
| 0xA4 | 重启清除 | 指令计数器溢出 | 持续输入脉冲超 ±2147483647（电子齿轮比设置不合理） |
| 0xC8 | 重启清除 | 过流 | 电机电流超 8A |
| 0xDC | 动作解除 | 推压动作范围超限 | 进入推压段后有外力推电缸回推压开始位置 |
| 0xCA | 重启清除 | 过热（估算发热量，类似过载） | 实际电流超 2.5A 持续不同时间（反时效曲线，电流越小报警越慢） |
| 0xB8 | 重启清除 | 励磁检出错误 | 检查电机动力线 |

## 已确认的疑点（原编译不确定点，Fly 已逐条确认）

1. **两套协议并存**：电缸所有版本两套协议都并存，**推荐 0x1600 控制字模式**（C025）
2. **橙色线标注**：橙色 = 通讯线负（485B），手册"正"是笔误（C026）
3. **报警码列**：以"报警代码（HEX）"列为准（0x80/0x82…），ALM_DO 列不参考；"0x16 重复"误报解除（C027）

> ⚠️ 另注意：本报警表为**内驱 & 485 外驱版本**专用，SAC-N2 伺服驱动器的故障码表是另一套（C024）。
