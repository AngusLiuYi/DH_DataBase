## 一、常用参数设置（按键操作）

面板按键：SET（确认/进入）、ZERO（加数字/零点）、DISP（切换位置/进入）、UNIT（切换参数）

### 1.1 设置小数点位置

1. 压力显示界面长按 SET（约 2s）→ 显示 ALO1
2. 按 ZERO → 显示 99OA
3. 按 DISP → 显示 0000
4. DISP 切位置 + ZERO 加数字，改为 **1111**（进入设置密码）
5. 按 SET → 显示 01iN-d
6. 按 DISP 进入 → 显示 000000
7. ZERO 切换小数点位置（如 2 位）
8. SET 保存 → 长按 SET 退出

> ⚠️ 改变小数点位置时，若为 0-10V（±10V）模拟量输出，模拟量输出上下限数值也需对应修改；4-20mA 输出则修改输出上限。砝码标定时勿进入 84CALF 参数。

### 1.2 设置零点跟踪范围和时间

同 1.1 进入 1111 密码后，按 UNIT 切换参数，DISP 进入设置零点跟踪值。

## 二、砝码标定（第二章，30-34）

用标准砝码对压力显示器进行标定，建立力值对应关系。

## 三、模拟量输出设置（第三章，40-48）

设置模拟量输出（0-10V / 4-20mA）的上下限，对应压力量程。

## 四、报警输出设置（第四章，50-71）

设置 ALO1 等报警输出参数。

## 售后关键口径 ⭐

- 进入设置密码 **1111**（长按 SET → ZERO → DISP → 改 1111）
- 改小数点位置后，模拟量输出上下限、85cAlp/89Fr 参数要联动修改
- 砝码标定时**勿进入 84CALF 参数**
- 本 SOP 为按键式操作，与 [[manual-鑫精诚力显示器参数修改说明]]（可能是上位机/通讯方式）互补
