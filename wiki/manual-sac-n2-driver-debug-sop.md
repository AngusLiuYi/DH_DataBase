# 大寰电机调试SOP（SAC-N2 驱动器）

> **源文件**：`raw/manuals/usage/大寰电机调试SOP_V1.1.pdf` ｜ V1.1 ｜ 29 页
> **适用产品**：SAC-N2 驱动器 + DLAR/DLARA 系列电机（音圈电机产品线，DL = Z 轴直线电机、AR = ZR 一体 2 自由度，详见 [[entity-音圈电机]]）
> **产品线**：[[entity-音圈电机]] / [[entity-驱动器]]
> **双轴定义**：轴1 = Z 轴（直线轴，通常上下方向使用），轴2 = R 轴（旋转轴，**内部有滑环，可 360° 无限旋转**）

## 概述

本手册覆盖 SAC-N2 驱动器的调试软件操作全流程：**软件连接 → 参数导入导出 → 寻相 → 回零 → 运动控制 → 增益配置 → 开环力控 → 故障码处理**。

## 三、寻相

DLAR/DLARA 系列电机（Z 轴为直线电机、R 轴为旋转轴，ZR 一体 2 自由度；详见 [[entity-音圈电机]] 型号体系）**上电后都需要寻相**，否则有飞车风险。

| 项 | 出厂默认寻相方式 | 备注 |
|---|---|---|
| Z 轴（轴1） | 自学习寻相 | |
| R 轴（轴2） | 二分微动寻相 | R 轴频繁角度辨识失败时可换自学习寻相 |

**手动寻相前置条件**：断开总线，电机处于**失能**状态，否则可能寻相失败。

**二次寻相校验**：记录两次寻相后的编码器位置角，差值 **< 10°** 为正常；差 **≥ 10°** 需重新寻相，直至收敛。

> 📷 界面截图：见原文件 P6-7 — 寻相操作面板（用于 Z 轴自学习寻相 / R 轴二分微动寻相；手动寻相需先断总线失能）

## 五、运动控制

通过调试软件实现电机的位置控制（单点运动 / 往复运动）。

- **单点位置运动**：设定目标位置，电机运动到位。
- **往复位置运动**：设定两点，电机往复运动。
- **R 轴控制方式与 Z 轴相同**，只需将轴1 切换为轴2。

## 七、开环力控应用

### 7.1 力控原理

走两段位置实现力控：

1. **第1段**：快速接近产品表面。假设压到产品位置为 15mm，第1段目标位置设为 **14mm**。
2. **第2段**：切换为慢速（**5—10 mm/s**），目标位置设为 **16mm**（超过接触点保证压到）。
3. **切第2段时同步修改电流限制 `0x5018`**：默认值 0，**1000 = 额定电流**，具体值根据所需压力及力传感器标定。
4. **压到判定条件**（满足以下 2 个条件即认为已压到产品）：
   - 条件1：`-10 < (0x6077 - 0x5018) < 10`，其中 `0x6077` = Z 轴实际转矩值；10 为阈值，可按实际调整。
   - 条件2：轴当前速度 **≤ 0.5 mm/s**；0.5 可按实际调整。

### 7.2 力控标定

#### 硬件构成
- 压力传感器：**XJC-608T-F**（鑫精诚品牌，用于标定电机末端实际压力；型号后缀不关注，详见 [[manual-xjc-608t-操作说明SOP]]）
- 电机：DLAR-20-40 及安装支架

#### 标定公式（线性关系 y = kx + b）

| 变量 | 含义 |
|---|---|
| y | 目标压力（g） |
| x | 转矩限制值（`0x5018` 设定值） |
| k | 系数（斜率） |
| b | 常数（截距） |

**k / b 计算公式**：
- `k = (y2 - y1) / (x2 - x1)`
- `b = y1 - (k × x1)`

**转矩限制值（0x5018）反算**：`x = (y - b) / k`

**当前压力换算**：`y = k × 转矩实际值(0x6077) + b`

#### 标定数据示例

| 组 | 设定值 0x5018 (x) | 压力 g (y, 5次平均) |
|---|---|---|
| 第1组 | 400 (x1) | 201 (y1) |
| 第2组 | 730 (x2) | 601 (y2) |

→ 计算得：**k = 1.212，b = -284**

**换算示例**：
- 目标压力 600g → `x = (600 - (-284)) / 1.212 = 729`，即 `0x5018` 设 729
- 目标压力 500g → `x = (500 - (-284)) / 1.212 = 647`
- 读到 `0x6077` = 729 → `y = 1.212 × 729 - 284 = 600g`

#### 标定 12 步流程

1. 选用高精度压力传感器；用砝码校准力传感器，高度调到与产品一致（电机内部有弹簧，高度不一致会有偏差）。
2. 电机回零 → 断使能 → Z 轴往下拉至轴末端与力传感器接触，记录电机位置（如 15mm）。非首次标定可省略。
3. 将 `0x5018` 改为 400（按实际设置）。
4. 电机速度设 ~10mm/s，加减速 10000mm/s²，目标位置 17mm（接触点 15mm + 2mm 余量，保证压到）。
5. 电机下行压到力传感器；若碰不到，说明 `0x5018` 太小，需加大直到力传感器有显示。若使用压力范围 200—600g，继续加大至显示值 ~200g，稳定 1—3s 后记录压力值。
6. 电机上行到 0mm 位置（建议力传感器上方 2mm 以上）。
7. 重复步骤 5，记录 5 组数据。
8. 将 `0x5018` 改为 700（按实际设置）。
9. 电机下行，若压力 < 600g 则加大 `0x5018`，直到显示 ~600g。
10. 按步骤 5、6、7 操作，记录 5 组数据。
11. 将数据填入标定表，算出 k 值及 b 值。
12. 按所需压力反算 `0x5018` 值。

## 八、常见故障码及处理

> **数码管显示规则**：左边第 1 位 = 轴号，右边 2 位 = 错误码。

| 错误码 | 含义 | 处理要点 |
|---|---|---|
| 1A | 编码器连接错误 | ① 检查编码器插头松动/插针脱落 ② 检查电机本体线缆接头/固定螺丝 ③ 断使能后手动拉动/转动轴，观察位置是否变化（无变化=编码器/线缆/驱动器问题）④ 交叉验证：更换电机/驱动器/线缆 |
| 0E | 位置偏差过大 | ① 检查动力线松动及 UVW 顺序（电机U-驱动器U, V-V, W-W）② 测 UVW 三相电阻，正常 **≤10Ω** ③ 断使能手动转动轴检查结构卡顿 ④ 交叉验证更换 |
| 07 | 角度辨识失败 | ① 检查编码器端子/电机端线缆接头，轴1/轴2线缆是否插错 ② 查寻相参数是否正确（参考第三章）③ 测 UVW 电阻 ④ 断使能手转动检查 ⑤ 交叉验证更换 |
| 09 | 电机过载 | 同 07/0A 处理流程 |
| 0A | 堵转电机过热保护 | 同 07/09 处理流程 |
| 19 | 驱动板辨识错误 | 检查驱动器逻辑电源接口及电机电源接口线缆是否漏接/松动 |
| 1B | 软件过流 | 同 19/1C |
| 1C | 电流零点过大 | 同 19/1B |
