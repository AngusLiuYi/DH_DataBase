# 三菱 PLC + 卓岚网关 简单 CPU 通讯配置 SOP

> ⚠️ **用途**：三菱 FX5U PLC 通过**卓岚网关（Modbus TCP↔RTU）**，用"简单 CPU 通讯"（无需编程）控制电缸/电爪
> **产品线**：[[entity-电缸]] / [[entity-电爪]]
> **关联**：[[manual-dh-485寄存器表总览]]（寄存器地址）、[[manual-dh-基恩士适配ecat盒子]]（另一类 PLC 适配）

---

## 一、网关侧配置（卓岚）

1. 官网 zlmcu.com 下载配置工具，连电脑后自动搜索网关
2. 设备管理 → 自动搜索 → 选中电缸/电爪连接的端口 → 编辑设备

**关键参数**：

| 参数 | 设定 |
|---|---|
| IP | 与 PLC 同网段且不冲突（PLC 10.10.17.95 → 网关 10.10.17.77） |
| 端口 | 默认 502（多个 Com 独立，可同端口用不同 IP 区分） |
| 工作模式 | PLC 主动连网关 → 网关设 **TCP 服务器**（本例 PLC 主站、网关从站） |
| 转化协议 | Modbus_TCP |
| 串口设置 | 按电缸/电爪串口参数 |

3. 高级选项保持默认 → 保存默认参数 → 加载核对 → 重启设备

## 二、PLC 侧配置（三菱 FX5U 简单 CPU 通讯）

1. GX Works3 新建程序 → 参数 → FX5UCPU → 模块参数 → 以太网端口 → 应用配置 → **简单 CPU 通讯设置**
2. 配置读取指令 + 循环时间

**关键参数**：

| 参数 | 设定 |
|---|---|
| 端口号 | 网关预设端口（如 502） |
| 本站端口号 | PLC 未用端口；**同一网关的两条指令也要不同端口**（如读 200 用 6900，读 201 就不能再用 6900） |
| 选项（16进制） | 网关所接电爪/电缸的**从站 ID**（默认 1） |
| 寄存器地址 | 选保持性寄存器，按电缸/电爪地址填 10 进制，映射到 PLC 未用变量 |

3. 检查校验 → 应用 → 下载 → PLC 诊断"简单 CPU 通信诊断"确认通讯正常

## 三、寄存器地址换算 ⭐（售后高频坑）

- 电缸/电爪地址表给的是 **16 进制**，PLC 侧要转 **10 进制**
- **初始化状态 0x0200 → 地址 40001+256 = 40257**（部分主控 Modbus 地址从 0 开始，则 40256；写入同理地址减 1）
- Device Id = 从站 Modbus RTU 地址（电缸/电爪默认 1）
- 寄存器类型 = 保持性寄存器（03 功能码，16 位整型）

## 四、Modbus TCP 报文解析（排障用）

Modbus TCP 报文 = Modbus RTU + 前 7 字节 MBAP 头：

| 字段 | 说明 |
|---|---|
| 交互标识（2B） | 事务处理标识，每条报文自加一 |
| 协议标识（2B） | 00 00（Modbus TCP） |
| 跟随字节数（2B） | 后面还有几字节 |
| 设备地址（1B） | 从站 ID |
| 功能码（1B） | 03 读 / 06 写单 / 10 写多 |
| 数据 | 寄存器地址 + 长度 + 数据 |

> 排障：通讯助手选"显示-数据流"查看报文；不能正常读取时用调试助手服务器版模拟网关测试。

---

## 售后关键口径 ⭐

- **地址换算**：0x0200 → 40257（16 进制转 10 进制 + 40001 偏移）
- **本站端口号每条指令要不同**（同一网关也如此）
- 网关工作模式：PLC 主站 → 网关 TCP 服务器
- Modbus TCP 与 RTU 报文差 MBAP 头（前 7 字节）
