## 一、产品总表与适用场景（P2）

| 系列 | 传动方式 | 最大行程 | 最大推力 | 典型场景 |
|---|---|---|---|---|
| **VLA** | 音圈电机+伺服 | 20~25mm | 30N（峰值） | 3C 检测：按键/面板/表带检测；汽车中控按键、开关检测；半导体芯片测试分选 |
| **DLARA** | 直线电机+闭环 | 25~60mm | 64N（峰值，35-50 型） | 精密装配、螺柱力控植入、BTB 扣合、移栽上下料、辅料贴装、IGBT 贴合 |
| **DLSRA** | 直线电机+闭环（经济型） | 25~50mm | 27.5N（峰值） | 3C 装配贴合、自动化移栽搬运；寻求价格适中的客户 |
| **DLE** | 直线电机 | 30~50mm | 54N（峰值） | 精密装配、线扫检测、力控推压定位、端子扣合、移栽上下料；新能源电池小件上下料 |
| **VLM/F** | 音圈电机（圆形） | 10mm | 30N（峰值） | 手机按键检测、键盘检测、晶圆清洗力控按压 |

> 注：以上为标品特性，不含定制化产品。

## 二、产品优势与精度口径（P3）

- 力控精度 **±5g**（部分 ±2g）、行程分辨率最高 **0.5μm**（光编）、重复定位 **±2μm**、旋转分辨率 0.00275°
- 极限厚度 **10mm**（VLA-10）、3 种工作模式（速度/力矩/位置）+ **软着陆**
- 对比传统组合式贴装焊头（DLARA-20-25 vs 传统方案）：位置精度提升 5 倍+、旋转精度 10 倍+、力控 2 倍+

## 三、售前 Q&A 速查（P5）⭐ 售后高频

| 问题 | 答案要点 |
|---|---|
| 安装方式影响？ | **垂直向下=常规**，按推荐使用；**水平/垂直向上=非常规**，可能电机出力不够 → 建议去除内部弹簧、减轻负载 |
| 控制线缆直径/弯曲半径？ | 分两根：动力线 ~7mm + 信号线 ~8mm；拖链弯曲半径要求 **≥8D** |
| 分辨率/重复精度/绝对定位精度关系？ | 分辨率=最小变化量；重复精度=多次动作一致性；绝对定位精度=实际与理想位置接近程度。分辨率高≠定位精度高（还受机械/电气/算法影响） |
| 什么是软着陆？ | 速度模式低力接近 + 持续监控位置误差；接触表面位置误差增大到预设值时轴保持在该位置。目的=接触过程力度可控、防损伤 |
| 力控精度能做多少？ | 常规线性旋转开环 **±10g 内**、高的 **±5g 内**、闭环 **±2g 以内**。负载越大、节拍越高越难控；音圈优于直线电机；控制器性能越好精度越高 |
| 支持哪些控制方式？ | EtherCAT、Modbus、CANopen、脉冲；**Profinet、（原文截断，未列完——待查证）** |
| 输出轴能受多大径向力？ | 精密器件尽量避免径向刚性碰撞；线性执行器可轻度滑动侧向受力，**侧向力建议 2N 以内**；**线性旋转执行器不建议侧向受力**（内部结构复杂） |

### 选型流程（P5）
1. 确认系列 → 2. 尺寸行程 → 3. 编码器类型 → 4. 环境（气压/电压）→ 核对负载/推力/力控精度三者 → 安全余量 → 控制器类型品牌 → 控制线缆类型线长

### 线缆安装要求（P6，售后抗干bits必读）
- 8 条安装要求：电机与线缆相对静止可直出/90° 弯折；上下相对运动需预留足够长度、控制横向摆幅；进出拖链两端固定、固定点远离弯曲端、U 型面平行；D1+D2 > 1.2H 无需隔离否则加隔板；线缆不重叠、留线径 10% 自由空间；气管与电缆间加隔离；线缆不可扭转；拖链内重量分布均衡
- 4 类常见失效：**芯线断裂**（长度不当拉扯/负载过大/固定点在弯曲活动区内）、**起旋和绝缘损伤**（弯曲半径过小）、**护套磨损**（周围无 10% 自由空间）、**屏蔽失效/EMC**（屏蔽角度不对+机械负载破屏蔽层）

## 四、命名规则（通用选型码）⭐

以 `DLARA 20 25 ZH1 RH1 24U BV M L1` 为例（P14）：

| 码位 | 含义 | 选项 |
|---|---|---|
| 系列号 | VLA / DLARA / DLSRA / DLE / VLM | |
| 第 1 数字 | 厚度 mm | 10/16/20/25/35/50/79 等 |
| 第 2 数字 | 总行程 mm | 10~60 |
| **直线编码器 Z 码** | 直线轴编码器 | **ZM2=磁编 1μm；ZH1=光编 0.5μm** |
| **旋转编码器 R 码** | 旋转轴编码器 | **RM2=磁编 0.005°；RH1=光编 0.00275°**（DLSRA 的 RM2 为磁编 2000 线） |
| 电压码 | 24=仅24V；**24U=主推 24V 可兼容 48V**；48=仅48V | VLA-30/DLARA 全系 24U；DLE 为 48V |
| 接口码 | **B=底部接口不带气路；BV=底部接口+带气路** | |
| 配件包 | 0=无 / 1=带IO线 / N=无配件包 | ⚠️ 2025.07 起**配件包码位于驱动器/线缆码前面** |
| 驱动器/线缆码 | **M=SAC2-NP1（大寰单轴）；Y=SAC-NP2（大寰双轴）；Z=SAC-NP4（大寰四轴）** + L1/L3/L5/L7/L10 线长 | DLSRA 特有：**MS=SAC2-NP1+研控 SSD2205PE-B1（研控单轴）；YS=SAC-NP2+研控 MS-MINI3E-2D（研控双轴）** |

> VLM 系列命名特殊（P29）：`VLM 50 C 10 H0 24U B S1 0 …`——50=厚度、C=交叉滚柱导轨、10=有效行程、**F=带力传感器/无=不带**、H0=光编0.5μm、力传感器量程码 S05=0.5kg/S1=1kg/S2=2kg、出线方式 S=尾端/B=正面
> VLM 编码器码全集：**M2 磁编1μm / H1 光编0.5μm / H0 光编0.5μm / HN20 光编20nm**（P29 注：磁编 1um、光编 0.5um、光编 0.1um、光编 20nm 四档，与码名对应关系见原文）

### 控制线缆料号体系（X775-xxxx）

执行器&驱动器线材匹配表（P30）按"执行器型号前3码 → 驱动组件 → 线缆长度 → 控制线缆料号"组织，配比关系：
- VLA/DLE 系列 + 单轴驱：**1 执行器 : 1 驱动器 : 1 线缆**（如 X775-0716-D1L01 = L1 1m）
- DLARA/DLSRA 系列：**2 执行器 : 1 双轴驱动器 : 2 线缆**（如 X775-0701-D1L01）
- 超长线缆（如 L10）为两段料号相加（如 X775-0559-D1 + X775-0721-D1L01）
- 线缆表中 "SAC-N2H+研控双轴驱动器" 为**文档错误，应为 NP2**（C020）；DLARA-13-25/13-45、VLA-25-10 为**客户定制特殊尺寸（非标品）**，仅厚度区别、使用与标品一样（C021）

## 已确认的疑点（原编译不确定点，Fly 已逐条确认）
