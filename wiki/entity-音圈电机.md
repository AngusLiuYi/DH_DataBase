# 音圈电机

> 大寰四大产品线之一。在售体系已按《音圈选型手册 CN-3.3.2025.10》全面更新（见 [[manual-dh-音圈选型手册]]）。

## 定义

音圈/直线电机执行器产品线本体。在售标品系列：**VLA（线性）/ DLARA（线性旋转）/ DLSRA（线性旋转经济型）/ DLE（直驱线性模块）/ VLM·VLMF（圆形闭环力控）**。配套 [[entity-驱动器]] 中的 SAC-NP2 / SAC2-NP1 / SAC-NP4 驱动器。

## 型号演进与在售状态（据手册版本记录 P31）⭐

| 系列 | Z 轴 | R 轴 | 状态 |
|---|---|---|---|
| VLA | 音圈电机 | 无 | **在售** |
| **VLAR** | 音圈电机 | 有（滑环无限旋转） | **2025.06 退市** ⚠️ 售后仍会遇到在役设备 |
| DLA | 直线电机 | 无 | **已退市（出货量很少）**（C019）——非被 DLE 替代，本身量少停售 |
| **DLAR** | 直线电机 | 有 | **2025.06 更名为 DLARA**（旧铭牌在役） |
| **DLARA** | 直线电机 | 有（滑环 360° 无限旋转） | **在售主力**（16/20/25/35 厚度全档） |
| **DLSR → DLSRA** | 直线电机 | 有 | **2025.06 更名 + 在售**（经济型，25 档） |
| **DLE** | 直线电机 | 无 | **在售**（79 厚度，48V，弹簧配置可选） |
| **VLM / VLMF** | 音圈电机（圆形） | 无 | **在售**（50C；VLMF 带力传感器闭环 ±0.3g~±1g） |

> 命名规则（[[corrections]] C001）：**VL=Z 轴音圈电机 / DL=Z 轴直线电机；A 后缀=无 R 轴；AR=ZR 一体**。
> 末位 A 迭代年份口径：**以音圈手册为准 = 2025.06**（C022，已更正"今年新推出"的旧说法）。
> ⚠️ 2025.07 起**定货码中配件包编码移到驱动器/线缆码前面**——读 2025.07 前后单据注意码位顺序差异。
> **定制非标口径**（C021）：DLARA-13-25/13-45、VLA-25-10 等未上册型号为**客户定制特殊尺寸（非标品）**——从型号可直接看出仅厚度区别，**使用方式与标品一样**；线缆表按标品同系列匹配。

## 关键轴定义
- **Z 轴**：直线轴，通常上下方向使用（力控下压场景）
- **R 轴**：旋转轴，内置滑环，可 360° 无限旋转（非有限角度）

## 驱动器配套（选型手册 P30）⭐

| 场景 | 默认驱动器 |
|---|---|
| **ZR 一体机（DLARA/DLSRA）** | **默认 SAC-NP2（大寰双轴）** |
| **单 Z 机（VLA/DLE/VLM）** | **默认 SAC2-NP1（大寰单轴）** |
| 四轴需求 | SAC-NP4 |
| DLSRA 经济方案 | **研控第三方：SSD2205PE-B1（单轴）/ MS-MINI3E-2D（双轴）**（第三方线材匹配需咨询大寰销售） |

- EtherCAT 细分型号：SAC-NP2-EC-U-03A1-03A2（双轴）/ SAC2-NP1-EC-A-03A2（单轴）
- 控制线缆料号 X775-xxxx 体系：单轴 1:1:1、双轴 2:1:2、超长线两段料号相加

## 售后要点速查

- 安装：垂直向下=常规；**水平/垂直向上=出力可能不够 → 去除内部弹簧、减轻负载**
- 编码器：ZM2 磁编 1μm / ZH1 光编 0.5μm；RM2 磁编 0.005°（DLSRA 为 2000 线）/ RH1 光编 0.00275°
- 电压：24 / 24U（主推24V兼容48V）/ 48（DLE、DLARA-35）
- 接口码：**B=底部接口不带气路；BV=底部接口带气路**（真空取放/吸嘴）；带气路版气压 -0.1~+0.2MPa、推荐负压 ≥-90kPa、流量 ≥6~8L/min
- 线缆：动力 ~7mm + 信号 ~8mm 两根，拖链弯曲半径 ≥8D；失效四类（芯线断裂/起旋/护套磨损/屏蔽失效）见手册 P6
- 侧向力：线性执行器 ≤2N；**线性旋转（DLARA/DLSRA）不建议侧向受力**
- 力控精度：开环 ±10g / ±5g；闭环 ±2g（VLMF 按量程 ±1g/±0.5g/±0.3g）；**DLE 仅水平无弹簧或竖直磁力弹簧下保证力控精度**
