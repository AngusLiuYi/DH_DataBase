# 音圈电机

> 大寰四大产品线之一。

## 定义

音圈电机产品线本体，含 VLA / VLAR / DLA / DLAR / DLARA 全系列。配套 [[entity-驱动器]] 中的原生 ECAT/CIA402 伺服驱动器（SAC-N2 / SAC2-N1 / SAC-NP2 等）。

## 型号命名体系

> 命名规则由 Fly 确认（见 [[corrections]] C001），是理解大寰电机型号的基础。

| 前缀 | Z 轴类型 | 备注 |
|---|---|---|
| **VL** | Z 轴为音圈电机 | |
| **DL** | Z 轴为直线电机 | 仍属音圈电机产品线 |

| 后缀 | R 轴 | 自由度 |
|---|---|---|
| **A** | 无 R 轴（仅 Z 轴） | 1 自由度 |
| **AR** | ZR 一体（Z + R） | 2 自由度 |
| **ARA** | ZR 一体（2026 新迭代内部版本） | 2 自由度 |

> 末位 **A**（如 DLARA / PGIA / PGEA / MCEA）= 2026 年新迭代内部版本标识，跨产品线统一规则。

### 型号矩阵

| 型号 | Z 轴 | R 轴 | 自由度 | 备注 |
|---|---|---|---|---|
| VLA | 音圈电机 | 无 | 1 | |
| VLAR | 音圈电机 | 有（滑环 360° 无限旋转） | 2 | |
| DLA | 直线电机 | 无 | 1 | |
| DLAR | 直线电机 | 有（滑环 360° 无限旋转） | 2 | 力控标定示例用 DLAR-20-40 |
| DLARA | 直线电机 | 有（滑环 360° 无限旋转） | 2 | 2026 新迭代 |

### 关键轴定义
- **Z 轴**：直线轴，通常上下方向使用（如下压力控场景）
- **R 轴**：旋转轴，**内置滑环，可 360° 无限旋转**（非有限角度）
