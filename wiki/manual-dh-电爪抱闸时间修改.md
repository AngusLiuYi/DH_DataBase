# DH 电爪更改抱闸时间 SOP

> ⚠️ **用途**：修改电爪**抱闸触发时间**（夹持产品 n 秒后抱闸启动）
> **产品线**：[[entity-电爪]]
> **关联**：[[manual-dh-pgia-pgea-电爪操作手册]]（抱闸释放寄存器 0x0506）

---

## 修改步骤（7 步）

| 步 | 操作 |
|---|---|
| 1 | USB 转 485 调试线连接电爪与电脑 |
| 2 | 打开大寰软件，选对应 com 口建立连接 |
| 3 | 点「帮助」→ 登录管理员权限，输入密码进管理员界面 |
| 4 | 返回主界面 → 视图 → 寄存器 |
| 5 | 滚轮找到 **0x1100 寄存器组** |
| 6 | 改抱闸触发时间（夹持 n 秒后抱闸启动，按工况修改） |
| 7 | 找到 **0x300 寄存器表 → 保存写 1**，保存完成自动变 0 |

> 断电重启生效。

## 售后关键口径 ⭐

- **抱闸触发时间 = 夹持产品 n 秒后抱闸启动**，寄存器组 **0x1100**（寄存器表见 [[manual-dh-485寄存器表总览]]，具体为 0x1108「抱闸触发时间」，默认 60 秒）
- 改完必须在 **0x300 写 1 保存**（Flash 保存，与电爪手册 0x0300 写入保存同源）
- **断电重启后生效**（不是即时生效）

## 参数由来与故障关联 ⭐（C036）

- **为什么有抱闸时间参数**：电爪长时间夹持物料会因大电流**过热甚至烧坏**，所以设"夹持多久后主动打开抱闸断掉使能"
- **历史固件 bug**：开闭抱闸时**编码器丢一整圈 → 位置丢失**；且夹持状态判定靠电流，打开抱闸后电流消失就不再反馈夹持状态
- **售后启示**：遇到"**位置丢失 / 夹持状态突然消失**"类工单，先想到是不是**抱闸时间这个参数**导致的
