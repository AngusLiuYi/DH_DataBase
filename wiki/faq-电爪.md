# 电爪 FAQ（噗元项目）

> **源文件**：`raw/fae-qa/噗元FAQ_20250424.xlsx`（HDFAQ 表，欧姆龙噗元项目，大寰内部 FAE 整理）
> **产品线**：[[entity-电爪]]

## 概述

共 78 条电爪 FAQ（含分体式夹爪），按主题分 8 类：初始化/标定、指示灯状态、Modbus 通讯、IO 控制、位置/行程、夹持/掉落/抱闸、硬件故障、EC 盒子与其他。

> 高频根因速查：**红灯闪烁=未初始化**、**改通讯参数须断电重启**、**上电堵转=未配对（PGEA 外置款，见 C028）**、**位置丢失/夹持状态消失=抱闸时间参数（见 C036）**、**RGIC 旋转不准=齿轮背隙（见 C033）**。

## 一、初始化 / 标定（0x0100）

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 23001 | 初始化写 1 是什么意思 | `0x0100` 写 1 = **单方向初始化**，方向按初始化方向寄存器（张开/闭合）执行 |
| 23002 | 初始化写 165 是什么意思 | `0x0100` 写 165（0xA5）= **重新标定行程**，行程与反馈不准时用，标定后须保存 |
| 23011 | 0x01 和 0xA5 的区别 | 0x01=按方向寄存器做单方向初始化（找单侧极限位）；0xA5=无论任何位置，做一次闭合→张开的**全行程重新标定** |
| 24031 | 如何更改初始化方向 | `0x0301`：0=张开回零（默认）、1=闭合回零；改完 `0x0300` 写 1 保存 |
| 25140 | 如何实现上电自动初始化 | `0x0504` 设 1，`0x0300` 写 1 保存，断电重启生效 |
| 28191 | 默认初始化速度慢怎么调 | `0x1402` 改初始化速度（例：下发 80，`0x0300` 写 1 保存） |
| 24039 | 为什么断电重启后要初始化 | 编码器是**增量式**，只记相对位置，断电丢原点，每次上电须重新回原 |
| 24047 | 电缸和夹爪为什么都要初始化 | 同上，电爪/电缸均为增量式编码器，断电须重新归零 |

**初始化异常类**：

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 24028 | 初始化动作很小、不正常 | 夹爪靠**撞击硬极限回原**，有干涉会导致原点错误；确认无干涉后下发 165 标定，或增大初始化电流/速度再标定 |
| 24027 | RGIC 初始化只做旋转方向 | 夹持轴已在原点（R/G 灯均蓝即已完成）；若推不动指尖，可能指尖螺丝过长卡导轨导致堵转未完成初始化 |
| 24060 | 初始化时指尖一直在做初始化动作 | 客户程序**连续下发初始化指令**，指令只需写一次（上升沿） |
| 24062 | 上电后自行运动、灯变蓝紫 | 启用了上电自动初始化（`0x0504`=1），按需可关闭 |

## 二、指示灯状态

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 23003 | 指示灯有哪几种状态 | 4 态：**红闪=未初始化、蓝=到位、绿=堵转、绿闪=掉落** |
| 25114 | 红灯闪烁是什么意思 | = **未做初始化**，下发 `0x0100` 写 01 执行初始化 |
| 25096 | 指示灯不亮但能正常通讯控制 | 指示灯只作状态反馈，与通讯控制无关，坏了返厂 |
| 30276 | 上电指示灯不亮但软件能控制 | 同上，指示灯损坏，返厂维修 |
| 24056 | 红色常亮、软件连不上 | ①误进升级模式 ②内部程序丢失 → 联系技术支持或返厂 |

## 三、Modbus 通讯

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 23004 | 连不上大寰上位机 | 8 步排查：端口异常/485AB 接反（A 接 TR+、B 接 TR-）/驱动未装/机台漏电/调试线灯只闪发送/485AB 电阻异常（正常 165Ω 左右）/电源未接/改 ID 后未重启 |
| 23005 | 改完 ID 后连不上 | 改通讯参数须**断电重启**才生效 |
| 23006 | 出厂默认 ID 是多少 | ID=1，波特率 115200，8 数据位、1 停止位、无校验 |
| 23007 | 波特率能否随意改 | 须与主站一致；波特率越高越快但长距离抗干扰越差；所有设备波特率必须一致 |
| 24021 | Modbus-RTU 通讯参数有哪几个 | 波特率 / 数据位(7/8) / 校验位(无/奇/偶) / 停止位(1/2) / 设备地址(0x00 广播~0xFF)，全部须一致 |
| 23010 | 03/04/06/10 功能码 | 03=读保持寄存器、04=读输入寄存器(只读)、06=写单个寄存器、10=写多个寄存器 |
| 23012 | 485AB 电阻正常多少 | 两标准：AB 间 120Ω（112~128Ω）/ 164Ω（153~174Ω） |
| 25068 | 上位机弹「485AB 接反」 | 确认是否真接反；调换后仍不行，换调试线/笔记本交叉验证 |
| 25102 | 多台 485 并联无法通讯 | ①站号重复 ②其中一台 AB 电阻异常拖垮总线 ③并联过多电阻过小 → 单连改站号、返厂、建议用 485 集线器 |
| 25070 | 抗干扰措施 | 磁环 / RS485 隔离器 / 屏蔽层接地 / 与动力线分开 / 供电与强干扰设备分开 / 延长线用双绞屏蔽线并接地 |
| 25075 | 夹爪支持哪些通讯 | 本体仅 **485 + IO**；其他协议需通讯转接盒 |
| 25076 | 8 芯线缆颜色定义 | 查夹爪手册（黄标/蓝标/最新版三种线标，最新版直接看线标） |
| 25080 | PE 线是什么 | 保护接地线，接外露导电部分 |
| 27145 | 24V 与 GND 之间电阻 | 正常 **10KΩ 左右**（内部等效阻抗有差异，非无穷大/导通即正常） |
| 30269 | 机器人扫描不到夹爪 | ①通讯参数不匹配/夹爪损坏（用大寰软件测）②机器人不支持插件通讯（改用 IO）③插件版本低（升级） |
| 30271 | 机器人控制中夹爪断电重启 | ①线缆通讯不良（重固定航插/查破损）②机器人末端功率不足（改单独供电） |
| 30272 | 机器人报 485 通讯超时 | ①线缆通讯不良 ②初始化过程中发了其他指令导致报文异常 |

## 四、IO 控制

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 23016 | 怎么理解 NPN/PNP | NPN=低电平触发、PNP=高电平触发，按电路需求选 |
| 24022 | IO 控制设置流程 | ①`0x0504` 设 1（上电自动初始化）②I/O 参数界面配 4 组参数 ③I/O 模式打开（`0x0402`=1）④保存后重启测试 |
| 24023 | 设完 IO 后上位机控制不了 | 打开 IO 模式后，**大寰上位机软件检测到 IO 模式开启，会禁用控制按钮**，所以上位机控制不了——485 通讯不受影响（IO 开关本身靠 485 改 `0x0402` 实现）。IO 与 485「先发先响应」，客户自己的软件/串口助手走 485 仍可控；恢复大寰软件控制需关闭 IO 模式（C039） |
| 25086 | IO 指令输入后不动作 | ①未开上电自动初始化/IO 参数错 ②主控输入输出类型与夹爪不对应（NPN/PNP） |
| 25085 | IO 和 485 能否同时控制 | 可以，遵循「先发先响应、后发后响应」。⚠️ 注意区分：大寰**上位机软件**打开 IO 模式后按钮被禁用无法控制（C039），但 485 通讯本身不受影响，客户自己的软件仍可走 485 控制 |
| 24046 | 哪些型号不支持 IO 模式 | RGIC-100-35、RGD-5、RGD-35、DH-3、DH-5 |
| 25118 | 型号 M1/2/3/4 是什么 | Modbus+I/O 类型区分：M1=485+IO(NN)、M2=485+IO(PP)、M3=485+IO(NP)、M4=485+IO(PN) |
| 25117 | 电爪本体支持什么通讯 | 常规标品本体支持 **485 和 IO** 两种 |

## 五、位置 / 行程

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 24038 | 绝对位置 vs 相对位置 | 绝对=以原点为基准，任何位置定位到同一处；相对=以当前位置为基准算距离方向 |
| 24045 | RGD 分辨率多少 | RGD 默认 **3600**；RGI/RGIC 默认 **360** |
| 24048 | RGD 背隙多少 | RGD **无背隙**；RGI 有背隙约 **±1°** |
| 24049 | 旋转范围多少 | RGI/RGD 支持**无限旋转**，旋转角度低位 `0x0105` 范围 -32767~32767 |
| 24051 / 25069 | 旋转角度低位/高位区别 | 低位（绝对）-32767~32767；高位（绝对）-160~160，实际角度 = 低位 + 高位×32768° |
| 28211 | 如何改旋转方向 | `0x050b` 旋转分辨率 360→-360（或 3600→-3600），`0x0300` 保存断电重启 |
| 27165 | 旋转角度要输入小数怎么办 | 改旋转分辨率 `0x050b`：默认 360=1°，改 3600=0.1° |
| 25116 | 什么是有效行程 | 指尖可自由活动的最大范围；夹爪行程 > 指尖需移动最大距离即适用 |
| 24025 | 位置反馈相反但能初始化 | PGI 系列**指尖装反**，拆下对调安装即可 |
| 24029 | 位置反馈与实际不符 | 初始化有干涉/动作有阻力→165 重标定；使用中→查指尖松动/编码器受干扰/硬件 |
| 24042 | 目标位置给 0 不能完全闭合 | ①无干涉下 165 全行程初始化并保存 ②改张开/闭合间隙参数优化 ③断电手动捏合看闭合情况 |
| 28212 | 支持调节打开/闭合间隙吗 | 支持：打开 `0x0510` / 闭合 `0x0511`，完全初始化后生效 |

| 24053 | 掉落指尖闭合还是维持 | 无抱闸→继续运动到目标位置；有抱闸→抱闸开启后维持在夹持位置 |

| 25097 | 夹持状态反馈慢/不反馈 | ①内部拟合参数过大 ②闭合位置设太大（到位但没夹到）→ 调闭合位置或设 0 |

## 七、硬件故障

|---|---|---|
| 24055 | 旋转到位后抖动 | RGD 直驱连接，负载不同需适配内部参数，抖动=参数不适配 → 联系技术支持 |
| 24057 | 运行中卡顿/断电手推卡顿 | ①自制指尖螺丝太长顶滑台 ②导轨异物 ③本体结构卡顿 ④撞击损坏 → 前三查、本体/撞击返厂 |
| 25063 | 运行噪音大 | 内部导轨滚珠异常，返厂维修 |
| 28194 | 误进升级模式无法控制 | 知硬件版本可远程升级，不知则返厂 |
| 28208 | 什么情况零电角丢失 | 保存过程中断电/上电大波动导致参数丢失；查 `0x1406` 是否变 0；保存后 `0x1105` 写 175 备份参数 |
| 25084 | 防水防尘吗 | 按型号防护等级，最高 **IP67**，第三方检测 |
