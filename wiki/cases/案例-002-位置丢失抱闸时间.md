# 现象（客户原话）
电爪夹着物料，过一会儿位置就丢了 / 夹持状态消失了。

## 追问过程
1. 是不是带抱闸的型号？→ 是
2. 是不是夹持一段时间后才出现？→ 是
3. 有没有改过抱闸时间参数？→ 有 / 默认值

## 定位根因
抱闸时间参数 = 夹持 n 秒后主动打开抱闸、断掉使能（防长时间夹持大电流过热烧毁）。但**旧固件 bug 在开闭抱闸时编码器丢一整圈 → 位置丢失**；且夹持状态判定靠电流，**打开抱闸后电流消失，就不再反馈夹持状态**。

## 解决方案
按工况调整抱闸时间参数（0x1108），或升级固件修复丢圈 bug。
