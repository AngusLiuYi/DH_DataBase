# 现象（客户原话）
电爪一上电就堵转，动不了。

## 追问过程
1. 什么型号？→ PGEA-2/15-10（外置驱动款）
2. 指示灯什么颜色？→ 堵转态
3. 是不是换过驱动盒 / 新装的？→ 是
4. 电爪和驱动盒是不是原配？→ 不是原配

## 定位根因
PGEA-2/15-10 是外置驱动款（电爪 + 驱动盒分离）。**电爪与驱动盒没有配对使用，导致参数无法与实际电机对应**，上电即堵转。

## 解决方案
确认电爪与驱动盒配对（原厂配对），或重新配对烧录对应参数。
