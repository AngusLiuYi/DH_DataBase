# 现象（客户原话）
有个 z 轴使能断了都不在 0 位，导致我回零老堵转。

## 追问过程
1. 型号？→ VLAR-20-15-M2-24-BV（音圈电机 ZR 一体，M2 磁栅，BV=底部接口带气路，已退市在役）
2. 回零方式？→ -1

## 定位根因
**-1 回零方式 = 碰挡板后反向走固定脉冲距离**（区别于 -3 碰挡板反向找 Z 脉冲）。客户把 -1 的「反向距离」参数设成了 **0**，电机碰挡板后反向走 0 距离 → 停在挡板位置，大电流报警堵转。

## 解决方案
把 -1 回零方式的「反向距离」参数从 0 改成合适值（本例 1000 脉冲），电机碰挡板后反向走 1000 脉冲、离开挡板走到正常待机位，回零完成。
