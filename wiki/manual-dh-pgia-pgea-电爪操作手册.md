# DH PGIA / PGEA 系列工业平行电爪产品操作手册

## 一、夹爪概况（P5-6）

### 指示灯定义 ⭐ 售后快速判态（比电缸多"掉落"态）

| 状态 | 指示灯 |
|---|---|
| 未初始化 | 红灯闪烁，其他灯不亮 |
| 初始化完成 | **蓝灯常亮**（进入可操作状态） |
| 收到命令 | 红灯快速闪烁一次（蓝灯常亮下呈**偏紫色**） |
| 夹住物体 | **绿灯常亮**，其他灯不亮 |
| 物体掉落 | **绿灯闪烁** |

> 电缸只有 4 态（无"掉落"），电爪 5 态多出"物体掉落=绿灯闪烁"——这是电爪独有状态。

### 引脚定义（8 芯航插，P6）

线序按线缆线标号码管接线（与电缸同源 8 芯：485A/485B/Out1/Out2/24V/In2/In1/GND）。线标丢失须联系大寰配合确认。

## 二、RS485 控制（P7-23）

### 默认通讯配置（P11）

| 项 | 默认值 |
|---|---|
| ID | 1 |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |

### 基础控制地址表（P13）

| 功能 | 地址 | 写入说明 |
|---|---|---|
| 初始化夹爪 | 0x0100 | **0x01 回零位；0xA5 重新标定**（闭合到张开全程） |
| 力值 | 0x0101 | 20-100 百分比（注意：电缸是 1-100，电爪下限 20） |
| 位置 | 0x0103 | 0-1000 **千分比**（注意：电缸是 0.01mm，电爪是 ‰） |
| 速度 | 0x0104 | 1-100 百分比 |
| JOG | 0x010A | -1 反向 / 0 停止 / 1 正向 |

### 反馈地址表（P13）

| 功能 | 地址 | 读取 |
|---|---|---|
| 初始化状态 | 0x0200 | 0 未初始化 / 1 初始化成功 / 2 初始化中 |
| 夹持状态 | 0x0201 | 0 运动中 / 1 到达位置 / 2 夹住物体 / 3 物体掉落 |
| 位置反馈 | 0x0202 | 实时位置 |
| 错误代码 | 0x0205 | 0 无错误，非 0 查报警代码 |

### 参数配置地址表（P13）

| 功能 | 地址 | 说明 |
|---|---|---|
| 写入保存 | 0x0300 | 1 写 Flash（写入持续 1-2 秒，期间不响应其他命令） |
| 初始化方向 | 0x0301 | 0 打开 / 1 关闭（默认 0） |
| 设备 ID | 0x0302 | 1-255（默认 1） |
| IO 参数测试 | 0x0400 | 1/2/3/4 |
| IO 模式开关 | 0x0402 | 0 关闭 / 1 开启 |
| IO 参数配置 | 0x0405-0x0410 | 4 组 ×（位置/力值/速度） |
| 上电自动初始化 | 0x0504 | 0 不初始化 / 1 自动初始化 / 165 完全初始化 |
| 停转 | 0x0502 | 1 规划性停转 / 2 恢复运动到刹车前位置 |
| 复位 | 0x0503 | 1 清除报警 |
| 抱闸释放 | 0x0506 | 1 打开抱闸 / 2 抱闸锁紧 |

## 三、关键命令详解 ⭐

### 初始化夹爪（0x0100）— 两个值的区别

| 写入值 | 行为 |
|---|---|
| **0x01** | 单方向初始化，按初始化方向（0x0301）找单向极限位，再按**上次保存的总行程**计算位置百分比 |
| **0xA5** | **完全初始化**：无论当前位置，执行一次"闭合到张开"全程，重新测量最大/最小位置 |

> ⚠️ **0xA5 初始化时若最大/最小位置被阻挡，会把阻挡位置误识别为行程边界**（如 0 位置识别为夹持物体宽度）——换指尖后必须 0xA5 初始化并保存。
> 0x01 的行程 = 上次 0xA5 初始化保存的行程。

### 夹持状态反馈（0x0201）四态 ⭐

| 返回值 | 状态 |
|---|---|
| 00 | 运动中 |
| 01 | 停止运动，未检测到夹到物体 |
| 02 | 停止运动，检测到夹住物体 |
| 03 | 夹住物体后，物体掉落 |

> 到达指定位置前夹住物体，反馈也是 02（夹住物体）。

### 力值 / 位置 / 速度 单位差异 ⭐ 与电缸对比

| 参数 | 电爪 | 电缸（对照） |
|---|---|---|
| 力值 | 20-100（%） | 1-100（%） |
| 位置 | **0-1000 千分比 ‰** | 0-65535，单位 0.01mm |
| 速度 | 1-100（%） | 1-100（%），但控制字模式 0.01mm/s |

## 四、IO 控制（P24-33）⭐ 含 NPN/PNP 双极性

### IO 模式配置步骤（P11）
1. 打开 IO 模式
2. 配置 4 组 IO 参数（位置、力）
3. 设上电自动初始化 0x0504=1
4. 保存写 Flash → 重启
5. 重启后自动初始化，状态灯变蓝 = 切换成功

### NPN 型（默认）INPUT 状态映射

| INPUT1 | INPUT2 | 执行 |
|---|---|---|
| 高阻(断开) | 高阻 | 第 1 组 |
| 0V | 高阻 | 第 2 组 |
| 高阻 | 0V | 第 3 组 |
| 0V | 0V | 第 4 组 |

### PNP 型（需提前与大寰沟通改配）INPUT 状态映射

| INPUT1 | INPUT2 | 执行 |
|---|---|---|
| 24V | 24V | 第 1 组 |
| 高阻 | 24V | 第 2 组 |
| 24V | 高阻 | 第 3 组 |
| 高阻 | 高阻 | 第 4 组 |

### OUTPUT 反馈（电爪 4 态）

| OUTPUT1 | OUTPUT2 | 状态 |
|---|---|---|
| 高阻 | 高阻 | 运动中 |
| 0V | 高阻 | 到位（未夹物体） |
| 高阻 | 0V | 夹住物体 |
| 0V | 0V | 物体掉落 |

> ⚠️ **IO OUTPUT 引脚输出电流最大 50mA**；默认 NPN（低电平有效），改 PNP（高电平有效）需提前与大寰沟通。NPN 接 24V / PNP 接 0V 会损坏夹爪。

### IO 测试方法（P32-33，售后可用）

- **输入测试**：打开 IO 模式 → INPUT1 接 0V、INPUT2 悬空 → 应执行第 2 组参数；两线全接 0V → 第 4 组；全断开 → 第 1 组。四组均正确动作 = 输入正常。
- **输出测试**：万用表一端接 24V 正、另一端接 OUTPUT 线 → 到位时 OUTPUT1 显示 24V（即输出 0V，有电压差）、OUTPUT2 显示 0V（高阻断路）为正确。

## 五、注意事项（P37）

- 安装勿施加强烈冲击和过大力矩
- 手指非系统规划运行内被外力被动带动，可能导致夹爪异常
- 保持出厂控制参数，需调整联系技术支持
- **带抱闸机型建议独立电源供电**
- 配线/检查前先断电
