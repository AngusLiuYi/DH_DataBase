## 一、夹爪概况（P5-6）

### 指示灯定义 ⭐ 售后快速判态（比电缸多"掉落"态）

| 状态 | 指示灯 |
|---|---|
| 未初始化 | 红灯闪烁，其他灯不亮 |
| 初始化完成 | **蓝灯常亮**（进入可操作状态） |
| 收到命令 | 红灯快速闪烁一次（蓝灯常亮下呈**偏紫色**） |
| 夹住物体 | **绿灯常亮**，其他灯不亮 |
| 物体掉落 | **绿灯闪烁** |

> 电缸只有 4 态（无"掉落"），电爪 5 态多出"物体掉落=绿灯闪烁"——这是电爪独有状态。

### 引脚定义（8 芯航插，P6）

线序按线缆线标号码管接线（与电缸同源 8 芯：485A/485B/Out1/Out2/24V/In2/In1/GND）。线标丢失须联系大寰配合确认。

## 三、关键命令详解 ⭐

### 初始化夹爪（0x0100）— 两个值的区别

| 写入值 | 行为 |
|---|---|
| **0x01** | 单方向初始化，按初始化方向（0x0301）找单向极限位，再按**上次保存的总行程**计算位置百分比 |
| **0xA5** | **完全初始化**：无论当前位置，执行一次"闭合到张开"全程，重新测量最大/最小位置 |

> ⚠️ **0xA5 初始化时若最大/最小位置被阻挡，会把阻挡位置误识别为行程边界**（如 0 位置识别为夹持物体宽度）——换指尖后必须 0xA5 初始化并保存。
> 0x01 的行程 = 上次 0xA5 初始化保存的行程。

### 夹持状态反馈（0x0201）四态 ⭐

| 返回值 | 状态 |
|---|---|
| 00 | 运动中 |
| 01 | 停止运动，未检测到夹到物体 |
| 02 | 停止运动，检测到夹住物体 |
| 03 | 夹住物体后，物体掉落 |

> 到达指定位置前夹住物体，反馈也是 02（夹住物体）。

### 初始化状态反馈（0x0200）⚠️ V3.4 修正

| 返回值 | V3.3 写法 | **V3.4 写法（以此为准）** |
|---|---|---|
| 0 | 未处于初始化过程 | 未处于初始化过程 |
| 1 | ~~处于初始化过程~~ | **初始化完成** |
| 2 | 初始化中 | 初始化中 |

> ⚠️ **手册内部不一致**：V3.4 只改了 P13 的寄存器总览表，**P15 正文表 2.4（2.3.3.1 初始化夹爪）里仍是旧写法「1：处于初始化过程」**。以总览表为准。

### 力值 / 位置 / 速度 单位差异 ⭐ 与电缸对比

| 参数 | 电爪 | 电缸（对照） |
|---|---|---|
| 力值 | 20-100（%） | 1-100（%） |
| 位置 | **0-1000 千分比 ‰** | 0-65535，单位 0.01mm |
| 速度 | 1-100（%） | 1-100（%），但控制字模式 0.01mm/s |

## 三之二、推压段功能（V3.4 新增）🆕

> 手册只在 **P13 寄存器总览表**给出 4 个地址，**正文没有对应详解章节，目录也没有条目**。以下为地址表逐字摘录 + 基于电缸推压段的类比说明，**机制部分标注为推断，待 Fly / 研发确认**。

### 寄存器定义（P13 原文）

| 功能 | 地址（十进制 / 十六进制） | 取值范围 | 默认值 | 说明原文 |
|---|---|---|---|---|
| 推压段（总长度） | 268 / **0x010C** | 0-1000 | **0** | 配置推压段总长度 |
| 推压力 | 269 / **0x010D** | 1-100 | **20** | 配置推压段力 |
| 推压速度 | 270 / **0x010E** | 1-100 | **20** | 配置推压段速度 |
| 推压方向 | 271 / **0x010F** | 0 / 1 | **0** | 配置推压方向；0 = 默认闭合方向，1 = 张开方向 |

- 四个寄存器**均可读可写**，读取返回当前设定值，写入后需 **0x0300 写 Flash** 才掉电保持。
- 推压段默认 0 = **不启用推压**（默认行为与 V3.3 一致，升级固件不会改变现有动作）。

### ⚠️ 电爪与电缸的推压段地址完全不同（易踩坑）

| 功能 | **电缸**（MCEA 等） | **电爪**（PGIA/PGEA，V3.4） |
|---|---|---|
| 推压段长度 | **0x0102**（0-65535，0.01mm） | **0x010C**（0-1000，千分比） |
| 推压力 | 0x0101（1-100%） | **0x010D**（1-100%） |
| 推压速度 | 0x0309（1-100%，默认 20） | **0x010E**（1-100%，默认 20） |
| 推压方向 | 0x030A（0 正向/1 反向/2 双向） | **0x010F**（0 闭合/1 张开，**无"双向"选项**） |
| 控制字模式 | 0x1601 推压段行程 + 0x1605 Bit12 推压运动 / Bit13 推压方向 | **不支持**（C037：0x1600 控制字仅 PGHL/PGLS 支持） |

> 🔴 **别把电缸地址搬到电爪上**。电爪推压段是独立开的 0x010C-0x010F 段，跟电缸 0x0102/0x0309/0x030A 不通用。

### 推断的工作机制（待确认）⚠️

参考电缸推压段（[[manual-dh-mcea-电缸操作手册]]）与 PGHL 已有的推压段用法（[[faq-电爪]] 案例 25095），推测电爪推压段逻辑为：

1. 夹爪按常规位置/速度指令运动；
2. 进入**推压段**后，切换为**以推压力（0x010D）为限、以推压速度（0x010E）推进**的方式继续走完推压段长度（0x010C）；
3. 推压方向（0x010F）决定这段动作是往闭合方向压还是往张开方向撑。

**典型用途**（推断）：需要"压到位"而非"走到位"的场景——压装、贴紧、避免硬碰撞。PGHL 上已验证过的用法是：**夹持力大的电爪若不设推压段，指尖直接撞产品会报警**（案例 25095），设合理推压段/推压力即可规避。

> ❓ **不能确定的点**（需 Fly / 研发确认）：
> 1. 推压段是**在目标位置之后追加一段**，还是**替换最后一段行程**？
> 2. 触发条件：写 0x0103 位置指令后自动进推压段，还是另有使能位？
> 3. 推压段长度 0-1000 是**占全行程的千分比**还是**绝对千分比位置**？
> 4. IO 模式（0x0405-0x0410 四组参数）里有没有对应的推压段参数位？手册 V3.4 未写。
> 5. 是否所有 PGIA/PGEA 固件版本都支持？需不需要升级固件？

## 四、IO 控制（P24-33）⭐ 含 NPN/PNP 双极性

### IO 模式配置步骤（P11）
1. 打开 IO 模式
2. 配置 4 组 IO 参数（位置、力）
3. 设上电自动初始化 0x0504=1
4. 保存写 Flash → 重启
5. 重启后自动初始化，状态灯变蓝 = 切换成功

### NPN 型（默认）INPUT 状态映射

| INPUT1 | INPUT2 | 执行 |
|---|---|---|
| 高阻(断开) | 高阻 | 第 1 组 |
| 0V | 高阻 | 第 2 组 |
| 高阻 | 0V | 第 3 组 |
| 0V | 0V | 第 4 组 |

### PNP 型（需提前与大寰沟通改配）INPUT 状态映射

| INPUT1 | INPUT2 | 执行 |
|---|---|---|
| 24V | 24V | 第 1 组 |
| 高阻 | 24V | 第 2 组 |
| 24V | 高阻 | 第 3 组 |
| 高阻 | 高阻 | 第 4 组 |

### OUTPUT 反馈（电爪 4 态）

| OUTPUT1 | OUTPUT2 | 状态 |
|---|---|---|
| 高阻 | 高阻 | 运动中 |
| 0V | 高阻 | 到位（未夹物体） |
| 高阻 | 0V | 夹住物体 |
| 0V | 0V | 物体掉落 |

> ⚠️ **IO OUTPUT 引脚输出电流最大 50mA**；默认 NPN（低电平有效），改 PNP（高电平有效）需提前与大寰沟通。NPN 接 24V / PNP 接 0V 会损坏夹爪。

### IO 测试方法（P32-33，售后可用）

- **输入测试**：打开 IO 模式 → INPUT1 接 0V、INPUT2 悬空 → 应执行第 2 组参数；两线全接 0V → 第 4 组；全断开 → 第 1 组。四组均正确动作 = 输入正常。
- **输出测试**：万用表一端接 24V 正、另一端接 OUTPUT 线 → 到位时 OUTPUT1 显示 24V（即输出 0V，有电压差）、OUTPUT2 显示 0V（高阻断路）为正确。

## 五、注意事项（P37-38）

- 安装勿施加强烈冲击和过大力矩
- 手指非系统规划运行内被外力被动带动，可能导致夹爪异常
- 保持出厂控制参数，需调整联系技术支持
- **带抱闸机型建议独立电源供电**
- 配线/检查前先断电
