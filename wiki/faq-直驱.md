## 一、寻相

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 612365 | 音圈电机用哪种寻相方法 | ①**VLA/VLAR 音圈电机本体不需要寻相**（只有正负两根动力线）；②DLAR 直线电机 Z 轴：自学习寻相或霍尔寻相，R 轴：微动/二分微动寻相；③电缸：微动寻相，负载大可正负限位寻相；④DLE：自学习寻相；⑤SSI 绝对式：首次执行一次强拖寻相，换驱动器/电缸需再寻相 |
| 626370 | 参数正常但寻相失败怎么排查 | ①手转确认卡顿+看编码器反馈（带抱闸先开）②拉到中间上使能，飞车=UVW 接错（对调 VW 或 UV 换向使能）③负载大→增寻相电流 ④确认编码器类型与寻相方式匹配 ⑤万用表测 UV/UW/VW 电阻（一般 <10Ω，断路=线缆/电机断线）⑥交叉验证 |
| 612366 | 数码管显示 TUN/LUN 什么意思 | 正常自检后显示 100（连总线显示 888）；TUN=正在寻相（正常 3s 内成功）；卡住=设了上电自动寻相但接的是 VLA/VLAR 等不需寻相电机/空置轴有参数 → 关闭自动寻相使能并保存 |

## 二、回零

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 28218 | R 轴回原一直旋转找不到原点 | R 轴用 34 号回零找 Z 向确认原点；先判断可控运动还是飞车：①回零方式错（一般 33/34）②飞车 ③编码器 Z 相引脚松动 ④编码器损坏 |
| 626389 | Z 轴回零一直往下走 | ①光编才支持 -3 回零，磁编须接原点开关用 19/20 ②负载大→回零扭矩阈值增大（SDO 写入）③上位机测 ④查编码器端口 ⑤交叉验证；参数推荐高速 10mm/s、低速 5mm/s、加减速 10000mm/s² |
| 627390 | Z 轴找不到原点 | ①M2 磁编才支持找原点信号回零，光编用 -3 ②查原点开关接入（手动拉开关看 IO 变化）③上位机测 ④查端口 ⑤交叉验证；用 19/20 回零 |
| 627397 | 板卡选不了 -3 回零方式 | 多数控制卡只支持 1-36 号标准回零；用 SDO 向 `0x6098` 手动写 -3（byte 型，不支持负数用补码：-3 写 253、-1 写 255） |
| 628399 | 怎么回零/选回零方式 | ①有外部光电→按标准 CiA402 选；②无光电→看后缀：H1 光编选 -3，M2 磁编接光电到驱动器 IO 后选 19/20 |
| 630412 | 无法控制回零（欧姆龙） | 欧姆龙不调用驱动器本体回零，用自己逻辑配置。光编：找 Z 向，原点返回方法=无原点接近输入/保持原点输入，原点信号=Z 向输入，方向=正；磁编：原点开关下降沿，方法=接近反转/保持时间，原点信号=外部原点输入，方向=负 |
| 630420 | 多次回零零点有偏差 | 小偏差=回零参数不匹配；亚毫米级=干扰致 Z 相/原点开关误判。回零低速（10mm/s）、加减速高（10000mm/s²），加磁环/独立供电/走线避大电流 |

## 三、力控与软着陆

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 626375 | 不同驱动器力控参数区别 | ISD 力控限制 `0x60E0`（万分比，0-30000）；SAC-N2 轴一 `0x5018`、轴二 `0x5818`（千分比，0-3000）；电流反馈都用 `0x6077`（千分比，±3000） |
| 626376 | 力控给过压位置，怎么判正常保压 | 速度小于阈值（已停）+ 位置在区间 + 电流达设定值，综合判断 |
| 626382 | 力控重复精度过大排查 | 正常 VLA ±3g、DLA ±5g。①查标定参数 ②保证工作面与标定面高度一致（电机内有拉簧）③须给过压位置（电流判停）④需求力太小，电机抗自身阻力+拉簧会偶发下不来 |
| 626386 | 力控接触物料马上缩回且报警 | 先看报警：①位置偏差过大→过压 2-3mm 即可，加大跟随误差阈值 ②过载/过热→低速接触（高速急刹反电势大）、超额定推力长保压会保护性报警 |
| 626388 | 怎么控制软着陆 | 流程：①解除电流限制→②快速到产品上方 0.5-1mm→③电流限制到目标力→④慢速到过压位置→⑤检测力到达→⑥保压→⑦保压完成→⑧返回待机、离开产品后解除电流限制 |
| 627391 | 力控怎么读力曲线 | 标准音圈电机内**无力传感器**，只能反馈运行电流/实时转矩（`0x6077`）；通过标定高度下电流↔压力关系换算。注意：换算力值只在标定高度有意义 |
| 627393 | 力控写了值不生效 | ①确认地址及范围（SAC-N2 轴一 0x5018 0-3000/轴二 0x5818；相石 0x60E0 0-30000）②若地址被 PDO 映射，SDO 写入会被 PDO 覆盖→从 PDO 删掉或改用 PDO 读写 |
| 630407 | 力控能到多少节拍 | 软着陆：快速段/返回段按定位节拍算（3g、1000mm/s、30mm 约 80ms）；慢速段 5mm/s 走 1mm 约 120ms；综合（除保压）300ms 内（DLAR-20-40-H1 空载，实际以调试为准） |
| 630409 | 怎么标定力控 | ①回零→②断使能手拉到接触压力传感器记位置→③限制电流 T1→④过压位置+2mm、5mm/s 下压→⑤记压力 F1→⑥返回待机→⑦重复得 T2/T3/T4、F2/F3/F4→⑧输入标定计算器算 KB 值 |
| 630422 / 701423 | 内部软着陆节拍波动大（重复两条） | ①拆分节拍 log（参数传入/下降/保压/抬升，越细越好）②同步监控运行曲线确认电机本体影响 ③重点排查差异大段落 ④多数主站 SDO 读写耗时长且波动大，重点查 |

## 四、精度与参数

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 29245 | 定位精度多高 | 重复定位：光编 Z 轴 ±2μm、R 轴 ±0.02°；磁编 Z 轴 ±5μm、R 轴 ±0.1°。绝对定位精度=不同目标位置的绝对误差 |
| 630404 | 减速比多少/给 10mm 没走 10mm | H1 光编：Z 轴 2000 脉冲/1mm、R 轴 65536 脉冲/360°；M2 磁编：Z 轴 1024 脉冲/1mm、R 轴 16384 脉冲/360° |
| 630405 | CT 多少正常/最高速度 | 往复节拍=行程规划+整定精度分开算；3g 加减速、1000mm/s 算规划，30mm 约 61ms；整定 ±0.1mm=19ms、±0.05mm=25ms、±0.02mm=32ms（DLAR-20-40-H1 空载） |

## 五、选型与轴数

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 30247 | 一拖二占几个轴号 | SAC-N2 组态只占 1 个站号，轴按配置占 1 或 2 个；DLAR/VLAR 的 Z、R 轴独立控制，直接占 2 个轴 |
| 628400 | 电机配几个驱动器 | 单轴：VLA/DLE/MCE；双轴：DLAR/VLAR。驱动器带轴数：SAC-NP4=4 轴、SAC-NP2=2 轴、SAC2-N1/相石/高创=1 轴 |
| 626374 | ISD 迭代 SAC-N2 程序要不要改 | 都符合 CiA402，使能/点动/回零/定位指令一致。不用力控→不改程序只更新组态（换 XML）；用力控→改 I/O 映射地址：ISD `0x60E0`（0.1‰）→SAC-N2 `0x5018/0x5818`（1‰） |
| 626371 | 怎么改运动方向 | 相石：搜 2002/2122，0↔1 互换，保存断电重启；SAC-N2：参数表旋转正方向 CW↔CCW；高创：DIR 0↔1 改，MPHASE ±180（保持 0-360），DIR 和 MPHASE 同时改，断使能断总线改完重启 |
| 612367 | 总线正常但 PLC 报主回路 OFF（相石 ISD-A5） | 相石内部参数关联，适配欧姆龙需改 `0x2005` 主站类型=1 |

## 六、故障排查

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 626379 | 使能后直接飞车 | ①基本是未寻相成功：查寻相参数/动力线是否插反 ②上电自动寻相时多台同时寻相电源功率不足→按峰值电流配足额电源 |
| 626380 | 读不到位置反馈无法控制 | DLAR 2025 迭代后取消厚度 20 以下霍尔改用微动寻相，针脚定义变了→新款音圈配老线缆会异常；查本体序列号反查硬件版本+看线缆标签 |
| 626383 | 电机抖动 | 先确认频率幅度：高频振动/大幅飞车=PID 不匹配或线缆问题；小幅慢速晃动=伺服正常（整定区间约 ±2 脉冲），摆臂长末端晃动大属正常 |
| 627392 | 上使能高频抖动/大幅摆动 | ①重导入标准出厂参数 ②直线电机上逐一使能隔离干扰 ③换负载/超额定→降刚性或增大负载惯量 ④查电机末端 DB 头松动 ⑤交叉验证 |
| 626387 | 丢步/走不到位/定位不准 | 回零后位置距负硬限位约 5mm，异常时不断电手动回到顶看反馈偏差。①干扰丢脉冲→加磁环/独立供电/走线避大电流 ②线缆接触不良→重插 DB 头/理线防拉扯 ③编码器脏污→对调交叉验证 |
| 630406 | 电机发烫 | ①上电未动就发烫=参数导入异常/接错线→下使能排查 ②长保压会发热，≤40℃ 不影响寿命 ③温度很高=额定推力不足，评估换大推力电机 |
| 630411 | 吸不起物料/气管漏气 | ①确认是否过压/吸嘴物料匹配（手按吸嘴开真空测）②堵气管测负压 ③真空进电机堵吸嘴测负压 ④拆吸嘴堵输出轴测负压，逐步定位漏气源 |
| 630413 | 轴只能走一点，给大位置不报警不动作 | 最多是力控限制值被写小，走到一定位置电流达预设值就停 → 不用力控时回读电流限制地址写最大值 |
| 630421 | 上位机下不了使能/操作无反应 | 总线操作冲突；总线控制优先级高，用上位机调试/改参数需断开总线或拔网线 |
| 28192 | 频繁报 0x1A 编码器连接错误，清除后又出现 | ①编码器线接触不良（拖链重点查电机端接头）②外部干扰 ③驱动/编码器损坏；措施：查接地、`0x2001-Sub.25` ABZ 窗口滤波 0.1、`0x200A-Sub.15` 断线次数 100、加非晶磁环（动力线/编码器线） |

## 七、配套驱动器 EtherCAT 总线（SAC-N2）

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 630414 | PLC 扫描不到从站 | ①网线接反/松动 ②驱动器侧面标签 XML 与组态 XML 版本不一致 ③数码管是否完成自检进总线模式 ④部分主控不支持一拖多，需更新版本或手动添加 |
| 630415 | 主站无法进入 OP 状态 | ①XML 版本一致 ②主站 DC 同步时间与通讯周期一致，`0x200B-Sub.16` 通讯周期方式选择=0 |
| 630416 | 无法连接上位机 | ①com 口被占/选错（插拔 USB 确认）②通讯板假死→断电重启 ③工控机带电/干扰→换笔记本直连 ④调试线异常→交叉验证 |
| 630417 | 转矩模式不动作或飞车 | ①PDO 缺 `0x6080` 最大运行速度→手动加 ②CST 模式前给 `0x6080` 强制赋值（Z 轴 mm/s、R 轴 RPM）③正确设目标转矩/转矩斜率/速度限定，看 FB 块错误码 ④部分主控需手动切模式确认已进 CST |
| 626385 | 编码器线两根散线做什么用 | 预留光电开关线（一般绿/黄）：H1 光编闲置即可；M2 磁编接入驱动器 DI 并设为原点开关 |
| 630402 | 原点开关怎么接 | H1 光编不接；M2 磁编按驱动器接线（SAC-N2 轴一：绿→24V、黄→IO p7 Input2、公共端 p18→0V，DI2 设原点；轴二：黄→p11、公共端 p17；相石：黄→p9、公共端 p14、p1→24V） |
| 626381 | 怎么套磁环 | 动力线：非晶磁环，PE 单独摘出，UVW 三线同向绕 3 圈；编码器线：卡扣磁环，PE 单独摘出（Z 轴已接 R 轴可剪），PE 一般 1 号脚最粗 |
