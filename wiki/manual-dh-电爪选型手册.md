## 一、电爪 vs 气爪 / 新版 vs 老版（售前论据，P2）

### 电爪较气爪优势
- 速度稳定、动作无延迟（气爪速度波动大、延迟）；系统构成简化（电爪直连 PLC vs 空压机+三联件+电磁阀+传感器）
- 力可控可调：485 通讯快速调节，**精密力控最高 0.1N 力重复精度**；气爪需调整整个气路压强、速度与力耦合、无法低速大力

### 升级版较老版优势（PGEA 宣传口径）
外观 5 种精简至 2 种（仅分外置/内置驱动）｜抗干扰 ×2（国家级可靠性实验室）｜可更换直出线缆（无航插、松动螺丝调出线方向、换爪仅拆线缆根部）｜最薄 18mm｜交期 10 天｜PGEA 价格更实惠性能不降反增

## 二、选型注意事项（P4，售后核对必读）⭐

1. **夹持力核算**：普通搬运冲击状况、安全系数 a=4 时，**夹持力 ≥ 被夹持对象质量的 10~20 倍**；公式 `F = mg / (2×μ×a)`（2=手指数）。μ>0.2 时仍按 10~20 倍原则选定；大加速度/冲击需更大安全系数
2. **摩擦系数参考**：金属-金属（粗糙度 Rz3.2 以下）μ=0.1；一般金属 μ=0.2；橡胶/树脂等 μ=0.2 以上
3. **行程**：夹爪行程需大于工件最大最小尺寸差值（有效行程=指尖可自由活动最大范围）
4. **指尖**：指尖太长太大太重 → 惯性力/弯曲力矩影响性能和寿命
5. **外力校核**：垂直负荷 ≤ 允许负荷；力矩 ≤ 最大负载允许力矩；Mx/My 由 L1 计算、Mz 由 L2 计算，取较小 F 值

### 布线注意事项（P4，与电缸手册同源）
机械安装隔离（远离变频/伺服/直线电机、减震支架、等电位导通）｜电源/信号分开走线（双绞+编织网管/屏蔽双绞、星型接地禁止串联）｜超 3m 加磁环｜禁止与气动电磁阀线缆共线槽、禁止扎带缠线缆｜选做：隔离电源+滤波器（电网→滤波器→隔离变压器→电爪）

## 三、售前 Q&A 速查（P5）⭐

| 问题 | 答案要点 |
|---|---|
| 快速选型 5 条件 | 工件重量→夹持力；工件尺寸→行程；使用场景→系列尺寸；抓取需求→功能（掉电自锁/包络自适应/无限旋转）；环境→IP 等级 |
| 什么电机？ | **高能量密度永磁同步电机（高效无槽设计）**——高持续转矩、精密调速、低摩擦 |
| 精度？ | 位置重复精度最高 **±0.02mm**；位置分辨率 ±0.03mm；**力控精度最高 0.1N**（全球制造业 Top10 客户量产验证） |
| 内径夹持？ | 支持，打开和闭合都可力位控制+速度控制 |
| 旋转角度？ | RGI、RGD 系列支持**无限旋转** |
| 需要外配驱动器吗？ | 驱控一体设计（PGEA-2/15-10 为外置驱动+控制盒例外） |
| 掉落检测？ | 支持：运动/到位/夹住/掉落 4 种状态反馈（信息读取或指示灯颜色） |
| 夹紧判断？ | 4 状态反馈 + 指示灯（详见各系列操作手册） |
| 断电自锁？ | **带抱闸型号断电后保持约 85% 夹持力**（P11 注③：断 220V 电源时夹持力降到通电时 85%，物料不掉落） |
| 通讯协议？ | **标配 Modbus RTU(RS485) + Digital I/O(2进2出)；选配 TCP/IP、USB2.0、CAN2.0A、PROFINET、EtherCAT** |
| 485 挂多少台？ | **单条 485 总线接入多个大寰产品建议不超过 4 台**，否则可能通讯异常；超过 4 台联系业务进行出货调整 ⭐ |
| RS485转USB？ | **不再免费配置**（2025.04 起），A801-0036-WG 需另下单 |

## 四、命名规则（通用定货码）⭐

以 `PGE 5 S M1 L5 J0 F0 0026 O` 为例（P7）：

| 码位 | 含义 | 选项 |
|---|---|---|
| 夹爪系列号 | PGE/PGEA/PGSE/PGC/PGHL/PGIA/RGI/RGIC/RGD/AG/DH/CGE/CGI/CGC | |
| 数字 | 夹持力（N）+ 行程（mm） | 如 5-26、140-50 |
| **O / W** | 抱闸 | **O=不带抱闸；W=带抱闸** |
| **B / S** | 出线方式 | B=底部；S=侧面 |
| **M1~M4** | 通讯协议 | M1=Modbus(RS485)+IO(NN)；M2=(PP)；M3=(NP)；M4=(PN)——NN=NPN/NPN、PP=PNP/PNP、NP=NPN/PNP、PN=PNP/NPN |
| **L1/L3/L5/L10/L15/LX** | 线缆 | 延长线 1/3/5/10/15m；LX 不配线缆（PGEA 系列为直出线；PGSE 有 L1=1.5m 特例） |
| **J0 / J1** | 指尖 | J0=不配指尖；J1=标准指尖 |
| **F0 / F1** | 法兰 | F0=无法兰；F1=标准法兰（ISO 9409-1-50-4-M6） |
| 4 位数字 | 机器人短线 | **0100=优傲CB/E、艾利特CS、新松、韩华A、珞石CR；02=遨博xArm；03=大象；04=节卡；05=达明；06=珞石SR/ER；07=越疆MG400；09=斗山A；10=斗山M；11=艾利特EC；12=大族；13=纽路麦卡；14=法奥；15=韩华HCR；16=众为创造UF；17=珞石CR**（P30-37 各页均有此表） |
| RGIC/RGD 的 M | 通讯 | Modbus(RS485)；DH-3 为 T=TCP/IP；DH-5-6 为 M3=MODBUS-RTU/M4=RS485定制 |

> 短线硬件分档（P38）：**C01=小电流电爪（峰值<1.5A）通用/CB等品牌；C02=小电流（≤0.6A）适配越疆CR/节卡等**；大电流电爪（>1.5A）用通用款
