# SAC 伺服驱动器报警代码表

> ⚠️ **用途**：SAC 系列伺服驱动器（SAC-N2/NP2/NP4 等 EtherCAT 伺服）的**完整报警代码表**，含 EtherCAT 总线 0x603F 读取代码
> **产品线**：[[entity-驱动器]]
> **重要区分**：本表是 **SAC 伺服驱动器（EtherCAT/CIA402）故障码**，即 [[corrections]] C003 待补的那份；与 [[manual-dh-电缸报警代码解析]]（内驱电缸故障码表）是**两套体系**（C024/C032），不要混用。

---

## 一、两套代码的关系 ⭐

| 代码体系 | 说明 |
|---|---|
| **数码管故障代码**（0x01~0x27） | 驱动器面板数码管显示的短码，见 [[manual-sac-np2-product]] 第五章 |
| **0x603F 总线读取代码**（0x2xxx/0x7xxx/0x8xxx…） | EtherCAT 主站通过对象 **0x603F** 读取的完整故障码，本表新增 |

> 售后在 PLC/上位机侧读 0x603F 能拿到比数码管更细的代码；数码管只能看到两位短码。

## 三、EtherCAT 标准故障类别对照 ⭐

本表补上了 EtherCAT/CoE 标准故障类别，方便在 PLC 侧做故障分类：

| 0x603F 代码段 | EtherCAT 故障类别 |
|---|---|
| 0x22xx | 短路/对地漏电流 |
| 0x23xx | 负载级故障（I2t）/ 过流 |
| 0x32xx | 直流回路电压异常 |
| 0x43xx | 温度 |
| 0x52xx | 内部/看门狗/测量回路 |
| 0x63xx | 配置/参数错误 |
| 0x71xx | 电机堵转/过载 |
| 0x73xx | 编码器 |
| 0x75xx | EtherCAT 通讯/同步 |
| 0x84xx | 速度/跟随/飞车 |
| 0x86xx | 位置偏差/限幅 |
| 0xFFxx | 制造商指令（FF00h~FFFFh） |

## 售后关键口径 ⭐

- **0x603F 是总线侧完整故障码，数码管是短码**——上位机诊断用 0x603F 更精确
- **不可断电复位类**（见 [[manual-sac-np2-product]] 5.3）：0x02/0x03/0x0D/0x17/0x18/0x19/0x1B
- 故障原因 + 排障措施完整版见原 xlsx（本页只列代码对照）
