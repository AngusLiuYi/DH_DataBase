# PGLS 电爪校准偏置值 SOP（联赢激光现场）

> ⚠️ **用途**：PGLS 电爪**零电角校准 + 绝对值编码器校准 + 偏置校准**，保证现场同型号电爪给定相同位置时走距一致
> **产品线**：[[entity-电爪]]
> **来源**：联赢激光现场定制 SOP

---

## 准备

- 预装 DHGripper 软件的电脑、USB 转 485 调试线、USB 线
- ⚠️ 现场加工件会干涉电爪行程，需在标定前**将干涉件拆除**

## 一、连接

1. USB 线剪断接到 USB 转 485 模块 → 模块插电脑、散线端插电爪本体
2. 打开软件选正确 USB 口 → 点搜索 → 搜到夹爪信息后双击连接

## 二、零电角校准

| 步 | 操作 |
|---|---|
| 1 | 视图 → 管理员 → 登录管理员 |
| 2 | 观察实时电流图窗确认使能状态；无波动则点使能 |
| 3 | 点回零，能正常回零则**跳过零电角辨识**，直接到绝对值校准 |
| 4 | 若不能回零：寄存器翻到内部夹爪参数，给 **1500 寄存器写 1** |
| 5 | 快速读写界面写 **300 和 1**（快速保存到电爪内部）→ 写入门 |
| 6 | 管理员快速控制界面 → 点重启系统确认 |
| 7 | 再次确认使能正常 |
| 8 | 确保最大/最小行程内无障碍物 → 测试界面点「校准零电角」 |
| 9 | 电爪低速走到最大行程停顿再走最小行程，停止后看 **0x1406** 零电角偏差是否 **100~1000 以内**；否则断电重启重校 |
| 10 | 快速读写写 300 和 1 保存 → 断电重启 → 重新回零确认 |

## 三、校准绝对值编码器

1. 确认正常回零后**行程初始化**（缓慢张开到最大再闭合到最小）
2. 行程校准完成后，**1500 寄存器改为 0**，保存后重启系统
3. 重启后重新上使能，观察电流正常波动、电爪停止无动作时，**给 150b 写 1** 开始校准偏置
4. 电爪以固定步距张开-闭合走完全程后停止，自动计算**左偏置、右偏置**值
5. 电爪完全停止后，校准偏置值自动复位为 0
6. 重复"保存-重启"步骤，标定完成

## 售后关键口径 ⭐

| 寄存器 | 作用 |
|---|---|
| **1500** | 内部夹爪参数：写 1 = 进入校准/快速保存模式；写 0 = 关闭 |
| **300** | 快速保存（写入数据到电爪内部 Flash） |
| **0x1406** | 零电角偏差（正常 100~1000 以内） |
| **150b** | 写 1 = 开始校准偏置 |

> ⚠️ 零电角偏差不在 100~1000 内必须断电重启重校，否则走距不一致。
> 全程核心：**每次改寄存器后都要"写 300 和 1 保存 + 重启"**。
