## 一、电缸 vs 气缸 / 伺服 vs 步进（售前论据）

### 电缸较气缸的优势
| 维度 | 电缸 | 气缸 |
|---|---|---|
| 位置 | 多点位设置，重复定位精度 ±0.02mm（部分 ±0.01mm），精度由软件决定 | 磁性开关/机控阀定位，精度由限位块及安装决定 |
| 力 | 可控可调，可实现高速接近+低速推压 | 需调整整个气路压强；速度与力耦合，低速大力需气液转换器 |
| 速度 | 多段加减速、匀速，选大导程丝杆最快接近 1000mm/s | 速度波动大、动作延迟，标准范围 50~500mm/s |
| 平稳性 | 速度和推力稳定平滑 | 气体可压缩，运动平稳性差、启动慢 |
| 系统构成 | 可选内置控制器，接 PLC 即用，位置信息及时反馈、无需外置光电开关 | 需电磁阀+气管+控制电源+光电开关 |

### 伺服电缸较步进电缸的优势
- 步进 1000RPM 以上输出力矩急剧下降，3000RPM 时只剩 1/3 或更低；伺服额定转速内输出力矩不变
- 闭环步进速度上限 3000RPM，伺服可达 6000RPM 或更高
- 步进速度越快扭力越小 → 加速度急剧下降 → 加速段变长 → 节拍时长增加

### ADVANCE 新版较老版的优势（P2）
| 特性 | 说明 |
|---|---|
| 无缝切换 | 电缸安装尺寸及负载安装尺寸均无变化，新老版本无缝切换 |
| 交期 10 天 | 生产优化升级，交期缩短至 10 天 |
| 抗干扰 ×2 | 高性能隔离/抗干扰/屏蔽集成电路，电源与信号抗干扰能力提升 2 倍，经国家级可靠性实验室测试 |
| 可更换直出线缆 | 无需航插，松动螺丝即可调整出线方向；换伺服电缸仅拆线缆根部、保留原有线缆 |

## 二、售前 Q&A 速查（P3）

| 问题 | 答案要点 |
|---|---|
| 如何快速选型？ | **位置运动**：行程(运动距离)→负载(产品重量)→导程(运行速度)；**推压运动**：导程(推压力大小)→行程(推压距离) |
| 丝杆/电机类型？ | 滚珠丝杆 + 伺服电机 |
| 最大推力 vs 最大负载？ | 推力=静态轴向力（不需克服负载重量/阻力/加减速度）；负载=带动负载重量+克服外部阻力+承载重量+重力加速度+启停动静摩擦、保证寿命的推荐值 |
| 精度？ | 重复定位精度 ±0.02mm（部分 ±0.01mm） |
| 可否超负载/超速？ | 均不推荐：超负载降低零部件寿命；最大速度基于伺服电机额定转速 3000RPM，超速导致线圈老化、扭矩衰减 |
| 电源怎么选？ | **按电缸峰值电流选择开关电源**（电源电流过低无法正常工作） |
| 抱闸能否断电保持高精度位置/力？ | **不能**。抱闸仅满足垂直安装断电时抱住运动轴使负载不坠落，不具备断电高精度位置及力的保持 |
| 丝杆精度可否更换？ | 支持更换研磨 C5 丝杆，重复定位精度可达 ±0.005mm，需咨询业务 |
| 发热？ | 第三方温升测试：室温 27±2℃、45%~75%RH 长时间工作，表面温度保持 50℃ 以内 |
| 防尘防水？ | IP40，不具备良好防尘防水；可定制更高等级 |
| 洁净等级？ | 标准适用于万级以上洁净车间；定制最高满足百级 |
| 推压带载影响力输出？ | 水平+额定负载内：无变化；**垂直向上推压：实际推力=设定推力−负载；垂直向下推压：实际推力=设定推力+负载** |

## 三、选型流程与负载校核（P4）

### 选型流程
1. 选定负载安装方式（水平 / 水平侧立 / 水平吊顶 / 垂直）
2. 根据负载安装方式选择行程、最大速度、加速度满足的型号
3. 根据最大速度选择负载质量满足的型号（查速度-负载曲线）
4. 根据负载重量核算负载力矩是否满足要求

### 校核条件
- 行程 ≤ 各机型设定行程
- 最大速度 ≤ 选择行程时的最大速度
- 加速度 ≤ 0.2G 或 0.3G（依型号/导程）
- 使用力矩 M < 允许负载力矩（Ma/Mb/Mc）

### 力矩计算公式
- 静态力矩：`M1 = W × L × 9.8 / 1000 (N·m)`（W=负载 kg，L=作用点负载重心距离）
- 动态力矩：`M2 = W × L × a × 9.8 / 1000 (N·m)`（a=加速度）
- 使用力矩：`M = M1 + M2`
- 负载方向 A、B 需考虑行程因素：`L = T + Hn + 行程`；方向 C、D、E 无需：`L = T + Hn`

### RCEA-3M 出杆型特有注意事项（P13）
1. **驱动丝杆未配备止旋结构**：使用时必须在驱动丝杆末端增加导轨等止旋功能结构（否则丝杆随电机旋转而旋转，无法前后移动）
2. 水平负载质量是使用了外置导轨后的数值
3. 必须在行程零点及终点增加**机械限位**，避免伸出行程外导致电缸异常卡死
4. 安装段与止旋导向负载端：安装孔精度 ≤0.05mm，平行度 ≤0.02mm，否则异响、震动、电缸异常或损坏
5. **请勿使用浮动接头类连接驱动轴本体的止旋结构**（径向晃动产生径向负荷 → 误动作或过早损坏）

### 通用注意事项
- 原点复位时滑块会一直移动到 ME（机械末端），注意与周围物体干涉
- 各型号均提供：刚性形变量参考曲线（轴向弯曲/偏载/回转三向）、推力曲线（不同导程推力输出 vs 力设定百分比）、节拍曲线（已包含 30ms 通讯时间）

## 七、电缸现场布线注意事项（P3，售后抗干扰必读）

### 一、安装与布线（必做）
1. **机械安装隔离**
   - 避免将电缸直接安装在变频电机、伺服驱动器、直线电机等高干扰设备上；建议减震支架或隔离板（如铝制背板）
   - 避免在电缸控制线缆上叠加其他设备供电（如气阀、传感器）
   - 金属安装面需与电缸外壳良好导通，防静电积累（可涂导电膏）
2. **线缆管理**
   - 电源线：双绞线 + 金属编织网管，两端接地
   - 控制信号线（CAN/485/EtherCAT）：屏蔽双绞线，屏蔽层接控制器侧接地
   - PE 接地线：截面积 ≥2.5mm²，接地电阻 ≤2Ω（实测记录于维护日志）；多设备组网用**星型接地拓扑，禁止串联接地**
   - 线缆超 3 米需增加磁环抑制高频噪声
   - ⚠ 禁止与气动电磁阀/传感器线缆共用线槽；⚠ 禁止在电缸线缆上缠绕扎带（改用尼龙搭扣）

### 二、电源及信号防护性能提升（选做）
1. 电源隔离与滤波：电缸单独配置隔离电源模块；输入电源端加装滤波器，接线顺序：**电网 → 滤波器 → 隔离变压器 → 电缸控制器**，滤波器外壳与机柜接地排导通
2. 通信抗干扰：信号线加装隔离模块

## 已确认的疑点（原编译不确定点，Fly 已逐条确认）

> 原 4 个不确定点已全部确认，详见 [[corrections]] C014–C017。

1. **OC / OE1 含义**：O/W=抱闸码；**C=内置驱动器**（内置版）；E1/E2=编码器码（外置版）。
2. **MCE（无 A）与 MCEA 的关系**：带 A 为新推出的迭代（年份口径以音圈手册版本记录为基准 = **2025 年中**，[[corrections]] C022）；**旧版本市场保有量还很多，短时间不会完全退出**——售后场景新老两代长期并存，老版资料须持续维护。
3. **RCEA-3M 的 M**：**预留占位，无实际含义**，不需要管；出杆型由 R 前缀（Rod）标识。
4. **SAC-NF 与 SAC-NF2**：NF 系列分多个型号，**主力机型为 SAC-NF2**——与 SAC-NP2 **相同硬件、相同操作方式，仅烧录软件区别（后续会统一）**。SAC-NP2 的调试操作与参数表可直接参照用于 NF2。
