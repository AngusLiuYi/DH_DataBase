# DH RGD / RGI / RGIC 夹爪固件更新手册

> ⚠️ **用途**：RGD / RGI / RGIC 旋转电爪的固件更新 + 校准流程
> **产品线**：[[entity-电爪]]（旋转电爪，双电机耦合插补，[[corrections]] C033）
> **关联**：[[manual-dh-pgls-电爪校准偏置值]]（零电角校准）、[[manual-dh-485寄存器表总览]]

---

## 一、升级前准备

1. 夹爪连电脑，用大寰上位机控制张合，确认接线正确
2. **导出参数**（备份）：
   - 先 0x120d 设 0 → 导出参数
   - 再 0x120d 设 1 → 导出参数

## 二、固件更新流程

| 步 | 操作 |
|---|---|
| 1 | **0x1103 写 175** 进入升级模式（上位机断开，指示灯红灯常亮） |
| 2 | 关闭大寰上位机，打开 **Gripper IAP.exe** |
| 3 | 设好端口号 + 波特率 |
| 4 | 先选 **Rotate 文件**，点 enterboot，等 Status 显示 "enter bootloader" → 点 Start，进度条 100% = 旋转固件更新完成 |
| 5 | 再选 **Grip 文件**，点 Start 再次升级 |
| 6 | 断电重启生效 |

## 三、恢复默认参数

- **0x1104 写 165** 恢复默认参数（最新版本可直接输入，旧版本需快捷方式写入）
- 恢复后先软件重启

## 四、校准 ⭐（RGD 与 RGI/RGIC 顺序不同）

> ⚠️ **关键区别**：RGD 先校准再设旋转原点；RGI/RGIC 先设旋转原点再校准。RGI/RGIC 每次标定原点后都必须校准一次。

### RGD（有抱闸，需先设 0x1107）

| 步 | 操作 |
|---|---|
| 1 | **0x1107 设抱闸类型**：0 不带抱闸 / 1 硬件控制抱闸（不带泄放，硬件版 1.0.0）/ 2 软件控制抱闸（带泄放，硬件版 2.0.0） |
| 2 | 校准零电角（**0x1100 写 165**）。⚠️ RGD5 减速比小，手指完全闭合校准成功率高；RGD35/RGD70 手指中间位置即可 |
| 3 | 校准失败（初始化状态反馈 ≠1）→ 重新校准 / 软件重启后再校 / 多校几次。一直失败可能硬件问题（硬限位/主板/电机异常） |
| 4 | 对照导出的参数，恢复拟合参数、PID |
| 5 | 设旋转原点：按导出参数设 0x1504、0x1505，**0x1506 写 2**，等自动变回 0 = 原点设置完成 |
| 6 | 保存参数（0x0300 写 1）→ 软件重启 → 能正常初始化+控制 = 完成 |
| 7 | 恢复客户参数（0x0300、0x0500 组）→ 设唯一码 → 保存 |

### RGI / RGIC（无抱闸，0x1107 默认 0 不设）

| 步 | 操作 |
|---|---|
| 1 | 设旋转原点：按导出参数设 0x1504、0x1505，**0x1506 写 2**，等变回 0 |
| 2 | 保存参数（0x0300 写 1）→ 软件重启，确认保存成功 |
| 3 | 手指中间位置，校准零电角（**0x1100 写 165**），失败则多校几次 |
| 4 | 能正常初始化+控制 = 完成 |
| 5 | 对照导出参数恢复拟合参数、PID |
| 6 | 恢复客户参数（0x0300、0x0500 组）→ 设唯一码 → 保存 |

## 售后关键口径 ⭐

- 升级模式入口 **0x1103=175**，恢复默认 **0x1104=165**，校准零电角 **0x1100=165**
- **RGD 先校准后设原点，RGI/RGIC 先设原点后校准**——顺序错了校准不通过
- RGD 的 0x1107 抱闸类型要按硬件版本/是否带抱闸设对
- 校准一直失败先想硬件（硬限位/主板/电机），别在参数上死磕
