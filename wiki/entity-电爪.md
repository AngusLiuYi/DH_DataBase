# 电爪

> 大寰四大产品线之一。伺服电动夹爪（Servo-Electric Grippers），全系驱控一体（PGEA-2/15-10 外置驱动型除外）。

## 定义

电爪产品线本体，含四大家族：
- **工业平行**：PGE / PGEA（薄型迭代）/ PGSE（经济）/ PGC（协作，IP54~67）/ **PGHL（重载，PGHL-400-80 为 400N 档主力机型）** / PGIA（长行程 80mm，IP54）
- **工业旋转**：RGI / RGIC（齿轮传动无限旋转）/ RGD（直驱零背隙无限旋转）
- **关节型**：AG-160-95 / AG-105-145（红点奖自适应）/ DH-3 / DH-5-6（五指灵巧手，11 自由度）
- **三指对心**：CGE / CGI / CGC（圆柱工件定心抓取）

> 2025.08 版手册为新旧选型手册**合并版**；2025.04 起新增机器人短线码位、RS485转USB 模块不再免费配。

## 通讯体系 ⭐

- **标配**：Modbus RTU (RS485) + Digital I/O（2进2出）；DH-3 例外标配 TCP/IP 模块
- **选配**：TCP/IP、USB2.0、CAN2.0A、PROFINET、EtherCAT（需通讯转换模块，见 [[manual-dh-电爪选型手册]] 第六章）
- ⚠️ **单条 485 总线挂大寰产品建议 ≤4 台**，超过需出货调整（通讯异常高频根因）
- IO 组合码：M1=NN / M2=PP / M3=NP / M4=PN

## 命名速记

`系列 + 力 + 行程 + 出线(B底部/S侧面) + 通讯(M1~M4) + 线缆(L1~L15/LX) + 指尖(J0/J1) + 法兰(F0/F1) + 机器人短线(0100/02~17) + 抱闸(O不带/W带)`

## 售后要点速查 ⭐

| 主题 | 口径 |
|---|---|
| 抱闸断电保持 | 带抱闸型号断电后**夹持力降到通电时 85%**，物料不掉落 |
| 力控精度 | 最高 **0.1N** 力重复精度；位置重复精度最高 ±0.02mm |
| 旋转背隙 | **RGIC（齿轮）有 1~2° 背隙——旋转重复性高、绝对性低；RGD（直驱）零背隙**。"旋转位置不准"类工单先分系列 |
| RGIC-100-35 尺寸变更 | **2025-01-10 高度 159→174mm**，其余不变（旧图纸/备件注意） |
| 夹持力选型公式 | `F = mg/(2×μ×a)`，a=4 时夹持力 ≥ 工件质量 10~20 倍 |
| 定制指尖 | 各型号附"指尖长度-夹持力衰减/晃动量"实测曲线，长指尖掉力属正常特性 |
| 电机 | 高能量密度永磁同步电机（无槽设计） |
| 短线硬件 | C01（小电流<1.5A）/ C02（≤0.6A 越疆CR/节卡等） |
| PGEA-15-10 负载 | 2025.06 勘误改 0.25kg（旧版资料为 0.1kg 口径需注意） |
| PGHL-400-80 | **400N 档主力机型**（C023）；手册"咨询销售人员"指配置确认，型号本身定型 |
