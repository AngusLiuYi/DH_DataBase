# DH 485 寄存器表总览（电缸 + 电爪）

> ⚠️ **用途**：所有 **485 通讯（Modbus RTU）协议类**电缸、电爪的**寄存器操作地址**速查，通过 485 访问读写
> **产品线**：[[entity-电缸]] / [[entity-电爪]]
> **核心口径**（[[corrections]] C035）：**485 系列电缸电爪寄存器大量相同**，电缸操作在电爪上通用（如软重启）；共用同一个上位机软件 **DHGripperUI**

## 二、权限体系（通用）⭐

寄存器 **0x0000** 控制权限，全系通用：

| 写入值 | 权限 | 能力 |
|---|---|---|
| 0x0000 | 普通用户（默认） | 控制和设置基本参数 |
| 0x1111 | 高级用户 | 二次开发接口（部分型号） |
| 0x5555 | 工厂用户 | 配置序列号 |
| 0xAAAA | 管理员 | 拥有所有权限（改内部参数） |

> ⚠️ AG95、PGC300 权限不写 flash，重启恢复普通用户；其余型号权限可保存。

## 三、通用寄存器地址速查 ⭐（电缸电爪基本一致）

| 高字节 | 功能组 | 关键子功能（低字节） |
|---|---|---|
| **0x00** | 修改权限 | 0x00 权限 |
| **0x01** | 基础控制 | 0x00 初始化/回零、0x01 力（电爪）/推压力（电缸）、0x02 推压段长度（电缸）、0x03 位置、0x04 速度、0x05 加减速（电缸）、0x06 相对位置（电缸）、0x07 点动 |
| **0x02** | 反馈 | 0x00 初始化/回零状态、0x01 夹持/运行状态、0x02 位置反馈、0x03 速度反馈、0x04 电流反馈、0x05 错误码反馈、0x06 力传感器/预留、0x07 编码器状态、0x08 输入IO状态、0x09 输出IO状态 |
| **0x03** | 用户参数配置 | 0x00 写入保存(Flash)、0x01 回零/初始化方向、0x02 设备ID、0x03 波特率、0x04 停止位、0x05 校验位、0x06 行程限制低、0x08 原点配置、0x09 推压速度、0x0A 推压方向 |
| **0x04** | I/O 配置 | 0x00 IO控制、0x01 IO引脚功能配置、0x02 IO模式开关、0x03 IO输入高低电平、0x04 IO输出高低电平、0x05-0x18 参数配置 |
| **0x05** | 特殊命令 | 0x00 强制开/闭、0x01 使/失能、0x02 停转、0x03 清除错误、0x04 上电自动回零/初始化、0x05 力控使能（电缸）、0x0C 系统失能/使能（电爪） |
| **0x0A** | 设备信息 | 0x00 型号、0x01 硬件版本、0x02 软件版本、0x03/0x04 序列号 |
| **0x11** | 内部控制 | 0x00 校准零电角、0x03 升级、0x04 恢复参数、0x05 备份参数、0x07 抱闸控制、0x08 抱闸触发时间 |
| **0x12** | 内部运动参数 | 拟合参数 a-d、位置/速度/电流环 PID |
| **0x13** | 内部实时数据 | 当前电流/速度/位置/参考值 |

## 四、电缸 vs 电爪 寄存器差异 ⭐

| 维度 | 电缸 | 电爪 |
|---|---|---|
| 位置单位 | **0.01mm**（0~65535） | **千分比 ‰**（0~1000） |
| 力 | 推压力（开环=电流百分比 / 闭环=克） | 夹爪力 20~100 百分比 |
| 独有寄存器 | 推压段长度 0x0102、行程限制、**力控 Kp/Ti/Td/T、力传感器量程/编号** | 抱闸释放 0x050C、抱闸触发时间 0x1108、初始化闭合/张开间隙、**掉落状态反馈** |
| 反馈状态 | 运行状态 0/1/2（运动/到位/堵转） | 夹持状态 0/1/2/3（运动/到位/夹住/掉落） |

## 五、SAC-NF 早期闭环力控（分体式电缸）⭐ 特殊

> ⚠️ [[corrections]] C034：**SAC-NF 是最早期闭环力控电缸驱动器，基于 SAC-N 的 485 协议研发**，与现在的 **SAC-NF2（EtherCAT 伺服驱动器）逻辑完全不一样**，不要搞混。

SAC-NF 寄存器在分体式电缸通用基础上，多出闭环力控参数：

- 0x0505 力控使能、0x050B 负载偏置、0x050C~0x050F 力控 Kp/Ti/Td/T、0x0510 力控规划时间、0x0511 力控规划减速度、0x0512 力传感器编号
- 力传感器量程（选外部力传感器 10V 对应推压力）
- 力传感器反馈 0x0206（单位克）

## 六、PGHL / PGLS（重载/长行程电爪）— 实为「电缸方案」⭐

> ⚠️ [[corrections]] C037：**PGHL / PGLS 虽属电爪分类，但功率比其他所有电爪大很多，主要用于新能源行业夹持电池，使用的是「电缸方案」**——寄存器单位、0x1600 控制字支持都同电缸。

- **寄存器单位同电缸**（位置 0.01mm，非电爪千分比）
- **支持 0x1600 控制字控制方式**（同电缸 2.4 控制字模式，见 [[manual-dh-mcea-电缸操作手册]]）
- **其他电爪都不支持控制字（0x1600）控制方式**

寄存器独有（电缸式）：
- **外部目标位置 / 外部相对位置**（外部编码器位置控制）
- **绝编当前位置**（外部绝对编码器位置反馈）、磁编芯片状态
- PGLS 独有：**位移锁力使能/位移锁力距离、开/关抱闸延时**

> 售后提示：遇到 PGHL/PGLS，**按电缸思路处理**（寄存器单位、0x1600 控制字），不要套用其他电爪的千分比/百分比口径。
