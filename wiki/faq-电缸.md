## 概述

共 50 条电缸 FAQ，按主题分 7 类：推压段/力控、初始化、回零、报警与故障、IO 控制、通讯、控制方式与参数。

> 高频根因速查：**130 报警=未初始化就收定位命令**、**红灯闪烁=未初始化（多为运行中掉电重启）**、**连续初始化=程序循环下发初始化命令**、**力反馈=电缸不支持，需选闭环力控电缸**。

## 一、推压段 / 力控

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 23015 | 推压段是什么意思 | 第二段推压行程：第一段走**位置模式**，第二段走**力矩模式**。推压力 `0x0101`、推压段位置 `0x0102`、目标位置；三示例（推压段 < / = / > 目标位置）说明位置段与力矩段分界，达到设定力即堵转停止 |
| 25082 | 推压运动标准控制流程 | ①给定目标位置/速度/加减速 ②给定推压长度、推压力 ③控制字写 **4129** 启动推压 |
| 27156 | 推压方向双向是什么意思 | 推压方向指推压段方向：正向=伸出、反向=缩回，**不支持双向**；`0x030A` 写 0=正向、1=反向 |
| 30253 | 最大推力 vs 最大负载 | 推力=对外施加的压力（如 1Kg 保压）；负载=垂直/水平可搬运重量（如装加工件） |
| 30254 | 能否超负载/超速使用 | 不能；超负载→电流增大升温→烧绕组绝缘甚至烧电机 |
| 30264 | 推压模式力值抖动震荡 | 传感器采样速率过低 → 采样速率调到最大 |
| 30286 | 推压过程电机异响 | 断使能开抱闸手动推拉：有异响=内部丝杆/导轨干涉返厂；无异响=PID 不匹配，降刚性测试 |
| 1428 | 电缸怎么实现力反馈 | 电缸**不支持力反馈**，需力反馈选**闭环力控电缸**（见 C034 SAC-NF≠NF2） |

## 二、初始化

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 23014 | 130 报警代码什么意思 | **未初始化就收到定位命令** → 清报警→初始化→再给定位命令 |
| 24024 | 使用中突然给命令不动、红灯闪烁 | 运行中发生重启，重启后未初始化 → 查接线/航插松动，必要时剪航插改对插端子打胶 |
| 24026 | 到达不了手册最大行程 | 初始化有阻挡→重新 165 标定行程并保存；或查 `0x0306` 行程限制值 |
| 27159 | 设了行程限制但没生效 | 165 初始化后限制会失效；**限制之后初始化要用 1 初始化**（不能用 165） |
| 1424 | 偶发回不了零 | ①原点状态一直初始化中 ②初始化电流过小（加大）③试校准零电角 |
| 1426 | 初始化不动作 | ①`0x0502` 停转=1（改 0）②电源功率不够 ③负载超额定（增初始化电流）④外驱须先使能再初始化 ⑤多台共用电源线径不够 |
| 1427 | 初始化设闭合却伸出 | ①485 程序初始化后自动发了伸出命令 ②IO 第一组位置设成了伸出值（改 0） |
| 1430 | 如何设上电自动初始化 | 上位机→寄存器→特殊功能 `0x0504` 设 1→保存 |
| 1433 | 一直在连续初始化 | 程序**循环发送初始化命令**，初始化是上升沿命令，只发一次 |
| 1441 | 默认初始化速度慢 | `0x120E` 寄存器值加大 |

## 三、回零

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 25094 | PLC 回原后当前位置与上位机不一致 | 欧姆龙回原由 **PLC 逻辑执行**（非调用驱动器回原），回原完 PLC 位置=0、上位机非 0 |
| 508334 | 怎么选择回零方式 | ①有外部光电→按标准 CiA402 选对应回零方式；②无光电→看型号后缀：E1（ABZ 需寻相）可选 -1/-3，E2（SSI 免寻相）可选 -1。注：**-1=碰挡板反向走固定脉冲距离、-3=碰挡板反向找 Z 脉冲**（-1 反向距离设 0 会堵转，见 [[corrections]] C038） |

## 四、报警与故障

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 25089 | 绿灯长亮代表什么 | **堵转** |
| 25077 | 怎么点动 JOG | `0x0107` 寄存器：-1 反向、0 停止、1 正向；速度用 `0x0104` |
| 25141 | 程序控制不了、软件可上下使能但点动回零无反应 | `0x0502` 停转寄存器=1 → 改 0 保存 |
| 28196 | 运行过冲 | 位置环 P 过大→过冲/低频抖动，速度环 P 过大→高频抖动；先微调位置环 P（默认增量 10 左右） |
| 30275 | 待机电流 1A 以上正常吗 | 不正常（正常待机 100-300mA 跳动）；多为寻相电流过小致零电角偏差 → 查接线/电源，增大寻相电流重新校准零电角 |
| 28175 | 励磁错误排查什么 | ①动力线/编码器线插紧 ②`0x1403` 编码器类型与本体一致（0=SSI/1=ABZ）③测动力线三相电阻 ④带抱闸先开抱闸再拉动 ⑤抱闸未全开也报警 |
| 1425 | IO 控制速度很慢 | ①速度参数设最大 100% ②设完须 `0x0300` 写 1 保存 |
| 1435 | IO 模式不定时位置抖动 | ①外部干扰（加磁环）②控制器输出点不稳（换点/查松动）③晃线缆复现→返厂检线缆 |
| 1436 | 总报偏差溢出 | ①低温环境（建议 0-40℃，低温需专用油脂）②负载/阻力大 ③动力线松动 ④PID 参数（联系技术） |
| 1437 | 初始化后自己伸缩 | 演示模式被打开 → 关闭 |
| 1438 | PLC 给位置就报警 | 确认报警代码，按报警表对应排查 |

## 五、IO 控制

| 编号 | 问题 | 根因与解决要点 |
|---|---|---|
| 24034 | 脉冲/16 点位/64 点位 | 脉冲=脉冲+方向高频控制；16/64 点位=数字量输入排列组合对应位置控制 |
| 24054 | IO 模式看状态反馈 | 两 Output 组合：都无=运动/未初始化；Out1 有 Out2 无=定位完成；Out1 无 Out2 有=推压到产品 |
| 25090 | 怎么启用 IO 模式 | 按视频 SOP；IO 模式一般还要开上电自动初始化 |
| 28170 | 上位机切换 PNP/NPN | `0x0403`、`0x0404`：0=NPN、1=PNP |
| 28171 | IO 控制但不想上电自动初始化 | 一体式 `0x0401` 设 1，用 input1 作初始化触发；分体式有单独初始化 IO 线 |
| 1434 | 给脉冲不动作 | ①IO 接线对不对 ②集电极还是 5V 差分（默认集电极，本体拨码调节）③输入输出类型与 PLC 一致 |
| 1439 | IO 反馈和以前不一样 | 之前用夹爪则 IO 反馈本就不一样（夹爪≠电缸） |
