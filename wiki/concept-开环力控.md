# 开环力控

> 大寰产品中常见的力控实现方式，通过限制电机电流（转矩）来间接控制压力，无需力传感器闭环反馈。

## 原理

走两段位置 + 限制电流实现力控：

1. **第1段（快进）**：快速接近产品表面。如接触位置 15mm，第1段目标设 14mm。
2. **第2段（慢压）**：切换慢速 5—10 mm/s，目标位置设 16mm（接触点 + 余量）。
3. **切第2段时修改电流限制 `0x5018`**：默认 0，1000 = 额定电流。
4. **压到判定**（满足 2 条件）：
   - `-10 < (0x6077 - 0x5018) < 10`（`0x6077` = Z 轴实际转矩值）
   - 轴当前速度 ≤ 0.5 mm/s

## 力控标定（y = kx + b）

| 变量 | 含义 | 地址 |
|---|---|---|
| x | 转矩限制值（设定值） | `0x5018` |
| y | 目标/实际压力（g） | — |
| `0x6077` | Z 轴实际转矩值（读数） | `0x6077` |
| k | 系数（斜率） | `k = (y2-y1)/(x2-x1)` |
| b | 常数（截距） | `b = y1-(k×x1)` |

**反算设定值**：`x = (y - b) / k`
**换算实际压力**：`y = k × 0x6077读数 + b`

> 完整 12 步标定流程见 [[manual-sac-n2-driver-debug-sop]] 第七章。

## 完整伪代码示例（两段位置限制电流实现力控，DLAR-20-40）

源文件 `两段位置限制电流实现力控_20230915.pdf` 的 8 步伪代码（通用线开环力控范例）：

```text
解封电流限制   ILIM 5.1           DLAR-20-40 最大电流 5.1A
快速接近产品   MOVEABS 24 1000    快速段到达产品上方 2mm 位置
等待到位       do{当前位置>23}while  等待快速段完成
限定电流       ILIM 1.0           根据标定的电流-压力关系限定合适电流
慢速扣合产品   MOVEABS 28 15      慢速接触产品，目标位置选接触点并过压 3mm
等待压力到达   do{反馈电流>=1000}while  根据电流-压力标定关系等合适电流到达
保压           delay 100ms        根据工艺选合适保压时间
返回           MOVEABS 0 1000     工艺完成，返回
```

> 要点：快进用大电流限制（5.1A），慢压段把电流限制降到 1.0（对应目标压力），靠电流-压力标定关系判定到位。

## 标定硬件

- 压力传感器：**XJC-608T-F**（鑫精诚品牌，用于标定电机末端实际压力；型号后缀不关注，与通用线 SOP 同型号，详见 [[manual-xjc-608t-操作说明SOP]] / [[manual-鑫精诚力显示器参数修改说明]]）
- 电机：DLAR-20-40（音圈电机产品线，DL = Z 轴直线电机、AR = ZR 一体 2 自由度，详见 [[entity-音圈电机]]）及安装支架
