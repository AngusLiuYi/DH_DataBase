# SAC-N2 驱动器初次上电 SOP

> **定位**：SAC-N2 驱动器从开箱到可被 PLC 控制的完整初调流程（6 大步）。
> **注意**：SAC-N2 已逐渐退市（由 SAC-NP2 替代，见 [[entity-驱动器]]），本 SOP 对在役设备仍有效。
> **配套视频**：`raw/manuals/usage/上电自动初始化_20231219.mp4`（自动初始化流程演示）。

## 流程总览

```
连接上位机 → 参数导入导出 → 确认电机参数 → 寻相 → IO 参数配置 → 屏蔽轴(仅双轴用单轴时)
     (一)         (二)           (三)        (四)        (五)            (六)
```

完成后电机初调完成，可直接用 PLC 控制。

---

## (一) 连接上位机（P1-2）

1. 设备上电后，用 **USB 转 TypeC 数据线**连接驱动器与工控机
2. 在设备管理器确认 COM 口——**插拔调试线，看哪个 COM 口闪动**

> 📷 界面截图：见原文件 P1-2 — 设备管理器 COM 口识别、软件连接界面（用于确认连接操作）

3. ⚠️ **打开 DH 上位机调试软件（DH-Robotics Servo Studio）**——与 DH 电爪电缸、ISD 音圈电机驱动器使用的**不是同一软件**，搞混了无法正常连接
4. 选择正确 COM 口，**波特率默认不变**，点击连接
5. 正常状态判据：弹窗显示"参数正常加载完成" **且下方实时电压有略微波动**

## (二) 参数导入导出（P3-5）⭐ 备份纪律

1. **调试前先保存原始参数**，以免无法恢复
2. 参数 → 保存；命名建议：**工位名称 + 序列号 + 版本**
3. 默认保存路径：软件安装目录下 `\settings` 文件夹

> 📷 界面截图：见原文件 P3-5 — 参数保存/导入/下载差异弹窗（用于参数备份与导入操作）

4. 导入调试参数：原界面点导入 → 选择参数表 → 点**下载**
5. 系统自动**比对原始参数与新参数的差异**并列在弹窗中，确认无误后点**下载差异**
6. 下载完成弹窗后，**建议再下载一次以上**（共 ≥2 次），确保参数正常写入
7. **部分参数断电重启才生效**：下载完成后需断电一次；**等驱动器指示灯完全熄灭后再上电，不可急上急下**

## (三) 确认电机参数（P6）

1. **单位转换为 mm**（方便后续调试）；**导程按实际电缸切换**
2. 带抱闸（刹车）型号电缸，**先手动打开抱闸**
3. 点抱闸控制按钮，正常可听到**"咔哒"声** = 抱闸已工作
4. 听不到声音 → 检查接线；或用万用表测 **BK+ / BK- 之间有无电压输出**
5. 抱闸打开后**用手推拉电缸感受顺滑度**——明显不顺畅可能是**辅助导轨干涉或负载过重**，需调整
6. 推拉过程中看上位机**位置和速度反馈是否与实际一致**，不一致查接线

> 📷 界面截图：见原文件 P6 — 单位/导程设置、抱闸控制按钮（用于电机参数确认）

## (四) 寻相（P7-8）

> ✅ **已确认（[[corrections]] C018）**：E2=SSI 单圈绝对值。**电缸 = 电机+丝杆，一个行程内转很多圈且无多圈计数器 → 必须回零**（"绝对值编码器免回零"的普遍认知在这里不成立）。但 **寻相只需初装时手动做一次并保存，后续上电不需要再寻相**（对比 ABZ：每次上电必须寻相，垂直重载还有失败风险）。SOP 本节描述的就是初装这一次寻相。

1. 判断编码器：型号含 **E2** = SSI（SOP 原文示例 `MCE-4G-05-075-E2-W-B`，⚠️ 这是**老版命名**，码位顺序与新版 MCEA 定货码不同）；也可导入参数后在 电机参数-编码器类型 查看
2. **关闭自动寻相**并下载参数
3. **示波器 → 寻相** 进入手动寻相界面；适配电缸时寻相方式可选**强拖寻相**，寻相失败可多尝试几次
4. 寻相成功后，控制**回零、往复运动**
5. 观察运动状态正常 → 电机已可使用

> 📷 界面截图：见原文件 P7-8 — 手动寻相界面、回零/往复运动控制（用于寻相操作）

## (五) IO 参数配置（P9-10）

1. 实际安装有**正负限位、原点开关**等，需在 IO 配置中设定
2. 点 IO 配置进入配置界面
3. 出厂默认所有 IO 点位**未定义**——用螺丝刀等物来回阻挡传感器，观察**界面哪个点位闪动**来确认对应关系
4. 确认点位后点下拉列表，按实际安装对应选择

> 📷 界面截图：见原文件 P9-10 — IO 配置界面、点位下拉选择（用于 IO 定义）

5. ⚠️ **选择完成后不要点保存按钮**，返回参数表界面
6. 点**上传**按钮，对 IO 配置界面进行同步
7. 之后将参数导出备份

## (六) 屏蔽轴（P11-12，仅双轴驱动器单轴使用时）

1. 选用 SAC-N2 双轴驱动器但实际只带一个轴 → 需**屏蔽轴二**
2. 上方切换到**轴二**
3. 参数表 → 电机参数 → **自动寻相使能 = 0**
4. 驱动器参数 → **内部调试模式使能 = 1**
5. 参数下载
6. **断电重启**
7. 至此电机初调完成，**可直接用 PLC 控制**

> 📷 界面截图：见原文件 P11-12 — 轴切换、自动寻相使能/内部调试模式使能参数位置（用于屏蔽轴操作）

## 售后速查卡（本 SOP 高频要点）

| 症状/场景 | 检查点 |
|---|---|
| 软件连不上驱动器 | 是否用错软件？SAC-N2 用 **DH-Robotics Servo Studio**（≠电爪电缸/ISD 音圈软件）；COM 口是否选对（插拔看闪动） |
| 连上但怀疑不正常 | 弹窗"参数加载完成" + **实时电压有轻微波动**才正常 |
| 参数改了不生效 | 部分参数**断电重启才生效**；断电后等**指示灯完全熄灭**再上电 |
| 参数写入不可靠 | **下载 ≥2 次**；用"下载差异"弹窗人工核对 |
| 抱闸无反应 | 听"咔哒"声；查接线；万用表测 **BK+/BK-** 电压 |
| 手推电缸不顺滑 | 辅助导轨干涉 or 负载过重 |
| 位置/速度反馈与实际不符 | 查编码器接线 |
| IO 功能不对 | IO 配置改完**不要点保存**，回参数表点**上传**同步 |
