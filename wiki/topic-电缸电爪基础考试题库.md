## 一、初始化

**Q1. 初始化写 1 和 A5 的区别？**
`0x0100` 寄存器。写 `0x01` = 单方向初始化（按 `0x0301` 初始化方向找单方向极限位，用上次保存的总行程算位置百分比）；写 `0xA5`(165) = 完全初始化/重新标定（无论当前位置，做一次"闭合→张开"全程，重新测最大/最小位置）。**换指尖后必须 0xA5 初始化并保存**。

**Q16. 如何更改初始化方向？**
寄存器 `0x0301`：0=张开回零（默认）、1=闭合回零；改完 `0x0300` 写 1 保存。

**Q17. 初始化方向改张开了，但发初始化命令还是先闭合再张开，为什么？**
①改了 `0x0301` 后没保存（`0x0300` 写 1）②发送的是 `0xA5` 完全初始化——0xA5 无论方向都固定做"闭合→张开"全程标定，不走方向寄存器。排查：确认发的是 `0x01` 而非 `0xA5`；确认 `0x0301` 已保存。

**Q34. 电缸和夹爪为什么断电重启后要初始化？**
用**增量式编码器**，只能记录相对位置变化，断电后原点丢失，每次上电必须重新初始化回原才能正常控制。

**Q36. 电缸上电初始化没反应，如何排查？**
①`0x0502` 停转寄存器=1（改 0）②电源功率不够（换大电源）③负载超额定（增大初始化电流）④外驱电缸须先使能再初始化 ⑤多台共用电源、线径不够。

## 二、指示灯

**Q2. 夹爪指示灯有哪几种状态，分别什么意思？**
5 态：**红灯闪烁 = 未初始化；蓝灯常亮 = 初始化完成；红灯快闪（蓝灯下呈偏紫）= 收到命令；绿灯常亮 = 夹住物体；绿灯闪烁 = 物体掉落**。

**Q40. 夹爪使用中突然给命令不动作，指示灯红灯闪烁，为什么？**
红灯闪烁 = 未初始化。使用中发生**掉电重启**，重启后未重新初始化。排查：查接线/航插是否松动（必要时剪航插改对插端子打胶），重新初始化即可。

## 三、Modbus 通讯

**Q5. 上位机连接不上夹爪/电缸，如何排查？**
8 步：①电脑端口异常 ②485AB 接反（A 接 TR+、B 接 TR-）③驱动未安装 ④机台 0V 与地间有漏电 ⑤调试线只闪发送灯 ⑥485AB 电阻异常（正常约 165Ω）⑦电源线未接 ⑧改 ID 后未断电重启。

**Q7. Modbus-RTU 通讯参数有哪几个？**
波特率（默认 115200）、数据位（8）、校验位（无）、停止位（1）、设备地址/ID（默认 1）。所有设备必须一致。

**Q8. 改完 ID 后连不上上位机，为什么？**
更改通讯参数（ID）后须**断电重启**才生效。

**Q10. 支持哪几种功能码？**
03=读保持寄存器、04=读输入寄存器（只读）、06=写单个寄存器、10=写多个寄存器。常用 03/06。

**Q11. 夹爪出厂默认 ID 是多少？**
ID=1；波特率 115200、数据位 8、停止位 1、无校验。

**Q13. 夹爪当前位置 500，串口助手读位置报文怎么写？返回报文是什么？**
读位置反馈 `0x0202`（功能码 03）。发送：`01 03 02 02 00 01 24 72`；返回：`01 03 02 01 F4 B8 53`（01 F4 = 500）。

**Q14. 给夹爪写 74% 速度，串口助手怎么写？**
写速度 `0x0104`（功能码 06），74% = 74 = 0x004A。发送：`01 06 01 04 00 4A 48 00`。

**Q53. 485A 和 485B 之间的电阻正常多少？**
两个标准：AB 间 120Ω（112~128Ω）或 164Ω（153~174Ω），因产品而异。

**Q42. 常给客户采取的抗干扰措施？**
①485AB 线加磁环 ②加 RS485 隔离器 ③线缆屏蔽层接地 ④产品线缆与动力线分开走线 ⑤供电与强干扰设备（抱闸/电磁阀/继电器）分开 ⑥延长线用双绞屏蔽线，屏蔽层与原装屏蔽层相接并接地。

## 四、IO 控制

**Q6. 怎么理解 NPN 和 PNP？**
NPN = 低电平有效（0V 触发）；PNP = 高电平有效（24V 触发）。主控输入输出类型须与夹爪对应。

**Q9. 夹爪设置 IO 控制的流程？**
①`0x0504` 设 1（上电自动初始化）②I/O 参数界面配 4 组参数（位置/力/速度）③I/O 模式打开（`0x0402`=1）④保存（`0x0300` 写 1）后断电重启，再用 IO 信号测试。

**Q18. 什么是高电平、低电平？**
高电平 = 接近电源正极（24V）的信号电平；低电平 = 接近 0V(GND)。NPN 低电平有效、PNP 高电平有效。

**Q19. IO 控制 input1/input2 组合对应哪几组位置？output1/output2 组合对应哪几种状态？**
INPUT（NPN 型，4 组）：in1 高阻+in2 高阻=第1组；in1 0V+in2 高阻=第2组；in1 高阻+in2 0V=第3组；in1 0V+in2 0V=第4组。OUTPUT（4 态）：out1 高阻+out2 高阻=运动中；out1 0V+out2 高阻=到位；out1 高阻+out2 0V=夹住；out1 0V+out2 0V=掉落。

**Q20. IO 控制下初始化后 output 两线有什么信号？万用表怎么测？**
初始化完成后（蓝灯）处于"到位"态：OUTPUT1 输出 0V（有效）、OUTPUT2 高阻（无信号）。测法：万用表一端接 24V 正、另一端接 OUTPUT 线——OUTPUT1 测得 24V（有电压差=有信号），OUTPUT2 测得 0V（高阻断路=无信号）。

**Q26. MCE-3G 电缸 IO 控制有几种状态反馈？**
3 态（OUTPUT 组合）：out1 高阻+out2 高阻=运动中；out1 0V+out2 高阻=到位（定位完成）；out1 高阻+out2 0V=堵转（推压到产品）。

**Q31. 上位机怎么切换 PNP/NPN？**
电缸：`0x0403`、`0x0404`——0=NPN、1=PNP。（电爪为 `0x0403` IO 输入电平、`0x0404` IO 输出电平选择。）

**Q32. 要 IO 控制又不想上电自动初始化，怎么办？**
一体式电缸：`0x0401` 设 1，用 input1 作初始化触发信号；分体式电缸：有单独初始化 IO 线，IO 打开后用初始化信号线触发。

**Q41. IO 控制时夹爪没控制就自己动作，为什么？怎么排查？**
①上电自动初始化（`0x0504`=1）上电时自动动作 ②演示模式被打开 ③程序中有张开/闭合指令。排查：关闭演示模式；断开 485AB 线看是否还动作；检查 `0x0504` 与程序。

**Q51. 设置完 IO 功能后，上位机控制不了夹爪了，为什么？**
打开 IO 模式后，**大寰上位机软件检测到 IO 模式开启，会禁用自身控制按钮**，所以控制不了。485 通讯不受影响（IO 开关本身靠 485 改 `0x0402` 实现）；IO 与 485「先发先响应」，客户自己的软件/串口助手走 485 仍可控。恢复大寰软件控制：关闭 IO 模式（`0x0402`=0）。⚠️ 沟通口径：客户说的「上位机」可能指客户自己的软件，大寰软件才叫「大寰软件」，先确认客户指哪个（C039）。

## 五、位置 / 行程

**Q15. 夹爪初始化状态和运行状态有哪几种，对应什么数字？**
初始化状态 `0x0200`：0=未初始化、1=初始化成功、2=初始化中。夹持状态 `0x0201`：0=运动中、1=到达位置(未夹到)、2=夹住物体、3=物体掉落。

**Q23. 绝对位置和相对位置区别？**
绝对位置 = 以原点为基准的固定坐标，无论当前在哪，发绝对定位都到同一位置；相对位置 = 以当前位置为基准，按距离和方向移动。

**Q35. 电缸实际行程没有手册写的大，为什么？怎么处理？**
①初始化时有异物阻挡，行程标定错误 → 重新 `0xA5`(165) 标定并保存 ②行程限制寄存器 `0x0306` 被设了值 → 检查/调整。

**Q38. 旋转夹爪旋转角度低位和高位的区别？**
旋转角度低位（`0x0105`）：-32767~32767，直接下发旋转角度；高位：-160~160，实际角度 = 低位 + 高位×32768°。

**Q44. 旋转角度要输入小数怎么办？**
改旋转分辨率 `0x050b`：默认 360 = 1°，改 3600 后低位单位变 0.1°，即可输小数角度。改完 `0x0300` 保存断电重启。

**Q47. 旋转夹爪旋转范围多少？**
支持无限旋转。旋转角度低位 `0x0105` 范围 -32767~32767（单次）。

**Q52. 0306 寄存器（行程限制）是干嘛用的？**
`0x0306` = 行程限制寄存器（单位 0.01mm），限制最大行程范围。⚠️ 设了限制后用 `0xA5`(165) 初始化会失效，须用 `0x01` 初始化才生效。

## 六、推压 / 控制字

**Q21. 电缸推压段长度怎么理解？**
推压段 = 电缸第二段推压行程。第一段走位置模式（快速接近），第二段走力矩模式（推压，达设定力即堵转停止）。推压段长度寄存器 `0x0102`。

**Q24. 电缸点动是哪个寄存器？正反转和停止写什么值？**
点动 `0x0107`（JOG）：-1=反向、0=停止、1=正向；点动速度用 `0x0104`。

**Q25. 电缸推压方向是什么意思？**
推压方向 = 推压段运动方向。`0x030A`：0=正向（伸出方向推压）、1=反向（缩回方向推压）、2=双向（不支持双向）。

**Q30. 电缸控制字使能、回零、触发定位、复位怎么控制？**
控制字 `0x1605`（bit 位）：使能 = Bit5（0 失能/1 使能）；回零 = Bit1（上升沿触发）；触发定位 = Bit0（定位标志，上升沿执行）；复位/清除报警 = Bit4（上升沿）。

## 七、报警

**Q28. 电缸报警 128 和 130 是什么原因？**
128 = 0x80 = 伺服 OFF 时收到移动指令（没使能就发运动指令）；130 = 0x82 = 回零未完成时的位置移动指令（没初始化/回零就发定位命令）。处理：先清除报警，再使能/初始化，最后才发定位。

**Q37. 电缸励磁错误排查什么？**
①动力线/编码器线插紧 ②`0x1403` 编码器类型与本体一致（0=SSI/1=ABZ）③断电测动力线三相电阻是否一致（相差过大返厂）④带抱闸先开抱闸再拉电缸看编码器反馈 ⑤抱闸未完全打开也报警。

## 八、选型 / 硬件

**Q3. PGI-140-80-W-S-M2 中 W 和 M2 代表什么？**
W = 带抱闸（O = 不带抱闸）；M2 = 通讯协议 Modbus(RS485)+I/O(PP)，即 PNP/PNP（S = 出线方式：侧面出线）。

**Q4. 夹爪使用功率怎么计算？**
功率 = 电压 × 电流 = 24V × 电流。额定功率 = 24V × 额定电流，峰值功率 = 24V × 峰值电流。选配电源按**峰值电流**选配（电流过低会无法正常工作）。

**Q12. 默写各功能寄存器地址**

| 功能 | 寄存器 | 功能 | 寄存器 |
|---|---|---|---|
| 初始化 | `0x0100` | 目标位置 | `0x0103` |
| 力值 | `0x0101` | 速度 | `0x0104` |
| 初始化状态 | `0x0200` | 夹爪状态 | `0x0201` |
| 位置反馈 | `0x0202` | 保存 | `0x0300` |
| 错误反馈 | `0x0205` | 推压力 | `0x0101` |
| 推压段长度 | `0x0102` | 清除错误 | `0x0503` |
| 上电自动初始化 | `0x0504` | IO 控制开关 | `0x0402` |

> 注：力值（电爪）和推压力（电缸）都映射到 `0x0101`，同一地址。

**Q22. 目标位置、速度、力用什么数据类型？**
都是 16 位无符号整型寄存器。位置：电爪 0~1000 千分比‰，电缸 0~65535 单位 0.01mm；速度 1~100 百分比；力：电爪 20~100%、电缸 1~100% 百分比。

**Q27. 线缆上 PE 线是什么线？**
保护接地线（Protective Earth），把设备外露导电部分接地，起安全保护作用。

**Q29. MCE-3G 和 MCE-4G 电缸区别？**
MCE-3G：行程 30/50mm、导程 1/2/4/6mm、水平负载 8kg/垂直 2kg、最大推力 200N（导程1）；MCE-4G：行程 75/150mm、导程 5/10mm、水平负载 15kg/垂直 6kg、最大速度 330mm/s（导程10）。4G 是大行程大负载版。

**Q33. 夹爪给 0 不能完全闭合，什么情况？思路？**
①初始化时指尖有干涉，位置标定错误 ②闭合间隙参数（`0x0511`）未设为 0 ③指尖设计不合理/太长。思路：先确认无干涉下 `0xA5`(165) 全行程初始化并保存，再查闭合间隙参数，最后断电手动捏合看机构闭合情况。

**Q39. 夹爪/电缸用 M2E-B1-1 盒子配欧姆龙 PLC，占不占节点？能用标准轴运动控制吗？**
占节点地址（组态要算节点），但**不支持标准运动轴控制**——M2E-B1-1 是 EtherCAT↔485 Modbus 转接，非标准 402 轴，只能用对应 XML 里的寄存器地址控制。

**Q43. RGD 旋转分辨率多少？**
RGD 默认 3600（RGI/RGIC 默认 360）。

**Q45. 分体式夹爪安装要提醒客户什么？型号是多少？**
型号：**PGEA-2/15-10**（外置驱动）。注意点：①电爪与驱动盒必须**配对使用**（参数与实际电机对应），未配对会上电堵转（C028）②接线正确、线缆连接牢固。未提醒的常见问题：上电堵转、位置反馈异常、初始化失败（根因多为未配对）。

**Q46. RGD 背隙多少？**
RGD 旋转方向零背隙（RGI 有 ±1° 背隙）。

**Q48. PGI-140-80 和 PGE-50-26 带不带抱闸，可否选配？**
两款都可选配抱闸：PGI-140-80（PGIA 系列）选型手册有 O(不带)/W(带) 抱闸码；PGE-50-26 也可选配抱闸（PGE-5/15/50/100-26 均可选配抱闸）。

**Q49. 夹爪和电缸支持哪些通讯方式？**
夹爪：标配 Modbus RTU(RS485) + Digital I/O(2进2出)，选配 TCP/IP、USB2.0、CAN2.0A、PROFINET、EtherCAT。电缸：485、IO、脉冲、PN、EC 五种控制方式。

**Q50. 8 芯线缆颜色对应哪些定义？**
绿=485A(通讯正)、橙=485B(通讯负)、黑=Output1、黄=Output2、红=24V、棕=Input2、白=Input1、蓝=GND、外壳编织线=PE(接地)。
