# 基恩士 KV8000/7500 PLC 适配 DH EtherCAT 盒子 SOP

> ⚠️ **用途**：基恩士 KV8000/7500 PLC 通过 DH EtherCAT 盒子（485→EtherCAT 网关）控制电缸/电爪
> **产品线**：[[entity-电缸]] / [[entity-电爪]]
> **关联**：[[manual-dh-m2e-b1-4通讯盒使用说明]]（通讯盒原理）、[[manual-dh-ecat盒子固件升级]]

---

## 一、XML 添加

1. 打开配置，选择对应 XML 文件添加（XML 文件联系 DH 技术支持获取）
2. 双击添加后的 XML 出现在界面

## 二、Modbus/RTU 配置说明

1. 双击进入 PDO 映射编辑
2. 选择 PDO 添加：**接夹爪选夹爪，接电缸选电缸**

## 三、变量绑定

- 一拖四盒子：1 号口接电爪、2 号口接电缸 → 分别绑**控制字**配置和**状态字**反馈
- 一拖一盒子：电爪输入/输出配置，控制/反馈变量自动映射到 PLC 内部地址

## 四、XH16EC 使能及夹爪初始化

- **XH16EC 模块使能节点必须置 ON**（参阅 KV-XH16EC 用户手册）
- 读夹爪反馈 → 夹爪完全初始化

## 五、夹爪简单运动控制

- 通过映射变量控制夹爪张合/运动

---

## 售后关键口径 ⭐

- **PDO 映射要选对设备类型**：夹爪选夹爪、电缸选电缸（与 M2E-B1-4 使用说明的"电缸电爪 PDO 互斥"一致）
- **XH16EC 模块使能节点必须 ON**，否则不通
- XML 文件需联系 DH 技术支持获取
