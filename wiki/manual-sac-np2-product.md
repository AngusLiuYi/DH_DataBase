# SAC-NP2 双轴驱动器（EtherCAT 型）产品操作手册

> ⚠️ **用途**：SAC-NP2 双轴 EtherCAT 伺服驱动器——电气连接、Servo Studio 安装、系统调试、报警处理
> **产品线**：[[entity-驱动器]]（SAC-NP2 主力双轴机型）
> **关联**：[[manual-sac-nf2-force-control]]（NF2 力控固件）、[[manual-sac-n2-ethercat-application]]（CIA402 应用）、[[manual-sac-np2-param-import-export]]（参数导入导出）

## 一、型号与规格（P12-16）

### 型号

| 型号 | 输出额定电流 | 峰值电流 | 额定功率 |
|---|---|---|---|
| SAC-NP2-EC-U-03A1-03A1 | 3A | 9A | 24V/72W，48V/144W |
| SAC-NP2-EC-U-10A1-10A1 | 10A | 30A | 24V/240W，48V/480W |

### 基础参数

- 双轴；控制方式 EtherCAT / IO / MODBUS / USB type-C
- EtherCAT 模式：位置/速度/力矩/混合
- 数字 IO：每轴 5 进 2 出；模拟量：每轴 1 路 0-10V 16bit
- 电源 24V(±10%)；电机电压 24/48V(±2%)
- 电机类型：BLDC、直线电机、音圈电机、PMSM 等
- 编码器：BissC/SSI/Endat/多摩川/ABZ

### 性能参数

- 过载 3 倍 >2.5s；最小 EtherCAT 周期 500us（更快联系技术支持）
- 滤波器 4+ 个（低通/陷波/抑振）；龙门 <10ns 级同步
- 编码器采样最高 23bit；速度环 3.5KHz；电流环最快 32KHz
- 保护：过流/过压/过热 + STO；重量 <0.6KG

## 二、电气接口（P18-33）

| 接口 | 功能 |
|---|---|
| Power | 逻辑电源 24V + 电机电源 24/48V + 制动泄放电阻 |
| Motor1/Motor2 | 轴1/轴2 三相动力线 + 抱闸控制输出 |
| Encoder1/Encoder2 | 轴1/轴2 编码器 |
| EtherCAT | 双网口，支持菊花链拓扑 |
| RS485 + STO | 485 通讯（默认115200，支持1M）+ STO1/STO2（都高才工作） |
| I/O | 数字输入(双向光耦 NPN/PNP) + 数字输出(晶体管 NPN 集电极开路) + 模拟量 + 脉冲 |

**关键接线参数**：
- 控制电源 24V 电流 ≥2A（含 DO 及抱闸）；动力电电流 ≥电机额定功率 3 倍
- DO 最大输出电流 0.5A/通道，总电流 ≤1.5A
- STO：仅当 STO1、STO2 都 24V 高时才工作

## 三、数码管状态显示（P46-48）⭐ 售后判态

### 显示逻辑
1. 上电初始化显示 **RST**
2. 初始化完成无故障：**最左位=总线状态机，中位=轴2模式，右位=轴1模式**

### EtherCAT 状态码

| 状态 | 码 | 含义 |
|---|---|---|
| Init | 0x01 | 未初始化 |
| PreOP | 0x02 | 已连接未运行 |
| SafeOP | 0x04 | 部分功能可用 |
| OP | 0x08 | 全功能激活 |

### 控制模式（6060H）

| 值 | 模式 |
|---|---|
| 1 | PP 轮廓位置 |
| 3 | PV 轮廓速度 |
| 4 | PT 轮廓转矩 |
| 6 | HM 回零 |
| 8 | CSP 同步周期位置 |
| 9 | CSV 同步周期速度 |
| 10 | CST 同步周期转矩 |

> 示例数码管 `888` = 总线 OP + 轴2 CSP + 轴1 CSP；`488` = SafeOP。

### 故障显示
- STO/POT/NOT/SS 特殊状态：三位同时闪烁
- 轴相关故障：最左位=轴号+点，右两位=十六进制故障码；双轴故障轮流显示（1s 周期）
- `8.8.8` 之类初始化失败 → 可能没烧 XML

## 四、显示面板错误码及处理（P49-53）⭐ 售后速查

> ✅ 完整故障码表（含 0x603F 总线读取代码 + EtherCAT 故障类别）见 [[manual-sac-伺服驱动器报警代码表]]（Fly 补投 Excel，闭环 C003）。下表为数码管短码。

| HEX | 错误名 | 故障原因要点 | 解除 |
|---|---|---|---|
| 0x01 | DI 功能重复分配 | 同功能分配多个 DI / 编号超范围 / 不支持 | 检查 DI 组参数 |
| 0x02 | 硬件过流 | 指令过快/制动电阻小或短路/电机线接触不良/UVW短路/增益振荡/编码器错 | **断电重启** |
| 0x03 | 飞车 | UVW 相序错/初始相位检测错/编码器错/负载大 | **断电重启** |
| 0x04 | 主回路过压 | 输入电压错/制动电阻失效或过大 | 检查输入与制动电阻 |
| 0x05 | 主回路欠压 | 电源不稳掉电/急加速压降/驱动器故障 | 检查电源 |
| 0x06 | 过速 | UVW 相序错/阈值过小/速度超调 | 查相序/调 0x200A.05 |
| 0x07 | 角度辨识失败 | 编码器校零失败 | 查 UVW 线序、电机参数 |
| 0x08 | 驱动器过载 | 电机与驱动器功率不匹配 | 换匹配驱动器 |
| 0x09 | 电机过载 | 负载重/增益发振/配线错/制动器未开 | 减负载/调增益/查配线 |
| 0x0A | 堵转电机过热保护 | 机械卡住/UVW 缺相或相序错 | 查机械/接线 |
| 0x0B | 散热器过热 | 环境温度高/风扇坏/内部故障 | 改善散热 |
| 0x0C | 编码器电池失效 | 断电未接电池/电池电压低 | 接/换电池 |
| 0x0D | 编码器数据异常 | 干扰/参数错/接线不良/编码器坏 | **断电重启** |
| 0x0E | 位置偏差过大 | 电机未转/增益小/0x200A.08 过小 | 查卡住/调增益 |
| 0x0F | 位置指令过大 | 同步周期位置插值大（已屏蔽） | 调增益/查同步周期 |
| 0x10 | 软件位置上下限设置错误 | 0x607D-01 < 0x607D-02 | 正确设置 |
| 0x11 | 原点偏置设置错误 | 原点偏置 0x607C 不在软限位内 | 正确设置 |
| 0x12 | 同步丢失 | 主站同步信号丢失 | 加大同步周期 |
| 0x13 | 未烧录 XML | 未烧录设备配置文件 | 烧录 XML |
| 0x14 | 同步周期配置错误 | EtherCAT 同步周期错 | 查 PLC 组态 |
| 0x15 | 同步周期误差过大 | 同步周期误差大 | 查组态/网线 |
| 0x16 | 参数辨识失败 | 辨识失败 | 用刚性表先跑起来 |
| 0x17 | 内部错误（看门狗） | 看门狗复位 | **断电重启**，联系厂家 |
| 0x18 | FPGA 配置错误 | FPGA 初始化失败 | **断电重启**，换驱动器 |
| 0x19 | 驱动板辨识错误（PowerID） | PowerID 错误 | **断电重启**，联系厂家 |
| 0x1A | 编码器连接错误 | 插头松/类型错/编码器坏/干扰 | 查编码器 |
| 0x1B | 软件过流 | 母线电压异常/电机线未接/STO 异常 | **断电重启** |
| 0x1C | 电流零点过大 | 电流采样自举失败 | 联系厂家 |
| 0x1D | EtherCAT 通讯故障 | 通讯断开 | PLC 重运行/Reset 恢复 |
| 0x1E | 速度跟踪误差过大 | 堵转/UVW断/转矩限制/增益小/干扰 | 查负载/增益 |
| 0x1F | STO 警告 | STO 信号无有效连接 | 检查 STO 端子 |
| 0x20 | 测温电阻异常 | 测温电阻损坏或未装 | 查连接 |
| 0x21 | 编码器 EEPROM CRC 错误 | 读 EEPROM 错 | 联系厂家 |
| 0x22 | 电机功率过小故障 | 伺服与电机功率不匹配 | 选匹配伺服 |
| 0x23 | 主回路缺相 | 电源线/UVW 接触不良/驱动器故障 | 查接线 |
| 0x27 | 霍尔信号连接错误 | 霍尔插头松/类型错/霍尔坏/干扰 | 查编码器 |

### 不可手动复位的错误（需断电重启）⭐

**0x02 硬件过流 / 0x03 飞车 / 0x0D 编码器数据异常 / 0x17 看门狗 / 0x18 FPGA 错误 / 0x19 PowerID 错误 / 0x1B 软件过流**

## 五、寻相方式（P56）⭐

| 寻相方式 | 适用场景 |
|---|---|
| 微动寻相 | 水平、负载不重、不在极限位/推压位 |
| 强拖寻相 | 垂直/水平单边限位 |
| 正/负限位寻相 | 垂直/水平双边限位 |
| 自学习寻相 | 直线电机水平或垂直、负载不重 |
| 霍尔寻相 | 直线电机、霍尔型增量编码器 |
