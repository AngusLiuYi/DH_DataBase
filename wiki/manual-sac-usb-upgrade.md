# SAC 系列驱动器 USB 固件升级操作指导

> ⚠️ **适用范围**：SAC 系列驱动器（SAC-NP2 / SAC2-NP1 等）通过 **USB 线连接上位机**进行**固件（APP 区）升级**。
> **产品线**：[[entity-驱动器]]
> 姊妹篇：[[manual-sac-n2-driver-debug-sop]]（DH-Robotics Servo Studio 上位机）

---

## 一、操作流程（7 步）

1. **连接**：驱动器（双轴）通过 USB 线与 PC 相连
2. **进入升级界面**：上位机左侧导航栏点「参数设定」→ 点「固件升级」按钮
3. **选文件**：点「浏览」选择待升级的 **.bin 文件**（⚠️ 必须是 .bin 后缀）
4. **进引导**：点「**Enterboot**」按钮，进入升级引导
5. **擦除**：界面显示"等待擦除"提示 → 正在擦除 **APP 区域**
6. **开始升级**：擦除完成后状态提示"可以升级"，**Start** 按钮变为可操作 → 点 **Start** 执行升级
7. **完成**：等待升级自动完成 → 重新烧写 APP 区后**驱动器自动重启**，上位机提示"等待重启"→ 最终提示"升级完成"

---

## 二、关键要点（售后速查）

| 项目 | 口径 |
|---|---|
| 升级对象 | 固件（APP 区域），文件为 **.bin** |
| 引导入口 | **Enterboot** 按钮 |
| 擦除提示 | "等待擦除"（擦 APP 区） |
| 执行按钮 | **Start**（擦除完成后才可点） |
| 完成后动作 | 驱动器**自动重启**，无需手动断电 |
| 失败风险 | 原文未提及中途断电保护措施——升级中**切勿断电/拔 USB**（通用经验，非原文） |
