# 售后排查引导清单（微信式追问模板）

> ⚠️ **用途**：客户描述现象常常很模糊、只有一句话。不要急着下结论，按本清单一步步追问、缩小范围。适用新人 FAE 培训 + 客户自助排查。
> **心法**：先定位产品线 → 看灯/数码管 → 按分支追问 → 对照高频根因。每一步都有判态依据，照问即可。

---

## 第一步：先定位产品线（必问）

1. 是**电缸 / 电爪 / 音圈电机 / 驱动器（SAC 系列）**哪一类？
2. 现象用一句话说：什么时候、做什么动作、什么表现？

## 第二步：看指示灯 / 数码管（最快判态，不用连软件）⭐

### 电缸指示灯（4 态，[[manual-dh-mcea-电缸操作手册]]）

| 指示灯 | 含义 | 下一步 |
|---|---|---|
| 红闪 | 未回零 | 先回零 |
| 蓝常亮 | 回零完成、就绪 | 正常 |
| 蓝闪一次 | 收到命令，执行中 | 正常 |
| 绿常亮 | **堵转** | 查负载/机械/行程限制 |

### 电爪指示灯（5 态，[[manual-dh-pgia-pgea-电爪操作手册]]）

| 指示灯 | 含义 | 下一步 |
|---|---|---|
| 红闪 | 未初始化 | 先初始化 |
| 蓝常亮 | 初始化完成、就绪 | 正常 |
| 红快闪（偏紫） | 收到命令 | 正常 |
| 绿常亮 | **夹住物体** | 正常 |
| 绿闪 | **物体掉落** | 查夹持力/指尖/工件尺寸 |

### 驱动器数码管（[[manual-sac-np2-product]]）

| 显示 | 含义 | 下一步 |
|---|---|---|
| RST | 初始化中 | 等待 |
| tUn | 寻相中 | 查寻相 |
| 888 | OP 正常 | 正常 |
| 488 | SafeOP | 查主站状态 |
| 闪烁故障码 | 有报警 | 查报警表 |

## 第三步：按产品线分支追问

### 电缸
1. **控制方式**？485（0x0100 直接寄存器 / 0x1600 控制字，[[corrections]] C025 推荐 0x1600）还是 IO 模式？
2. **是否回零成功**？读 0x0200 回零状态（0 未回零 / 1 成功 / 2 回零中）
3. **有报警吗**？读 0x0205 错误码，对照 [[manual-dh-电缸报警代码解析]] HEX 列
4. 绿灯=堵转？→ 查负载、行程限制（0x0306）、机械是否卡住

### 电爪
1. **初始化是否成功**？0x01（单向回零）vs 0xA5（完全初始化，换指尖后必须做）
2. **夹持状态** 0x0201 = 0 运动 / 1 到位 / 2 夹住 / 3 掉落？
3. **上电堵转**？→ 先确认是不是 PGEA-2/15-10 外置款，**查电爪与驱动盒是否配对**（[[corrections]] C028）
4. **位置丢失 / 夹持状态突然消失**？→ 查**抱闸时间参数**（0x1108，旧固件 bug 开闭抱闸丢编码器圈数，[[corrections]] C036）

### 音圈电机
1. **力控精度不对**？→ 开环（±10g/±5g）还是闭环（±2g，VLMF ±0.3~1g）；调 M/C/滤波（[[manual-sac-nf2-force-control]]）
2. **寻相问题**？→ ABZ 每次上电寻相（垂直重载有失败风险）vs SSI 初装一次即可（[[corrections]] C018）
3. **驱动器配套**？→ ZR 一体默认 SAC-NP2、单 Z 默认 SAC2-NP1（[[entity-音圈电机]]）

### 驱动器（SAC 系列）
1. **数码管显示**？→ 对照上面状态码
2. **报警码**？→ 0x01~0x27，注意**断电重启类**：0x02 硬件过流 / 0x03 飞车 / 0x0D 编码器异常 / 0x17 看门狗 / 0x18 FPGA / 0x19 PowerID / 0x1B 软件过流（[[manual-sac-np2-product]]）
3. **0x13 未烧录 XML**？→ 走烧录流程（[[manual-sac-n2-xml-update]]）

## 第四步：高频根因速查（一句话现象 → 最可能根因）⭐

| 现象 | 最可能根因 | 参考 |
|---|---|---|
| 电爪上电就堵转（PGEA-2/15-10） | **电爪与驱动盒未配对** | C028 |
| 电爪位置丢失 / 夹持状态消失 | **抱闸时间参数** + 旧固件丢编码器圈数 | C036 |
| 485 通讯异常、挂不上 | 单条总线超 4 台 | 电爪选型手册 |
| 旋转位置不准 | RGIC 齿轮背隙（1~2°）vs RGD 零背隙 | C033 |
| 电缸跟不上目标位置 | 电子齿轮比设置不合理 | 报警表 A4/D8 |
| 垂直重载寻相失败 | ABZ 每次上电寻相 | C018 |
| 电缸不回零就动作 | 没使能 / 没回零就发运动指令 | 报警表 0x80/0x83 |

## 通用提醒 ⭐

- **485 系列电缸电爪寄存器大量相同**，电缸操作在电爪上通用（如软重启）；共用 DHGripperUI 上位机（[[corrections]] C035）
- **PGHL/PGLS 是电爪却用电缸方案**（寄存器 0.01mm、支持 0x1600 控制字），其他电爪不支持控制字（[[corrections]] C037）
- **SAC-NF（早期 485 闭环力控电缸）≠ SAC-NF2（伺服驱动器）**，读资料先分清（[[corrections]] C034）
- 客户每说一句，先判断它落在哪一步，再问下一个问题，不要一次抛一堆可能原因
