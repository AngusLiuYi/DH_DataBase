# SAC系列驱动器USB升级操作指导文档

双轴通过usb线与PC相连后，点击左侧导航栏参数设定界面，然后点击固件升级按钮，进入升级界面。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqD473mE1pqVxe/img/ee0eaedb-b94b-4449-b24b-20373998c13a.png)

通过点击浏览，选择需要升级的bin文件，注意是后缀名为.bin的文件。并点击Enterboot按钮，进入升级引导。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqD473mE1pqVxe/img/d687c94e-dd3f-4052-95d1-6b9854a09d49.png)![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqD473mE1pqVxe/img/7702f499-6d3f-4d4b-969f-88912ef1b7d5.png)

此时界面会显示等待擦除提示，表示正在擦除APP区域。

擦除操作完成后，状态提示可以升级，此时Start按键可操作，点击Start进行固件升级。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqD473mE1pqVxe/img/c245d197-f182-40d4-a386-3bc16c954193.png)

等待升级操作自动完成。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqD473mE1pqVxe/img/3b8ce3b2-cced-4384-a41d-b99cd83d0211.png)

重新烧写APP区域后，驱动器自动重启，上位机提示等待重启。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqD473mE1pqVxe/img/e3c894ab-b82a-438e-89f6-dab425e9fb2c.png)

上位机提示升级完成。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/v9kqD473mE1pqVxe/img/644425a3-ee9d-46d8-92b1-68aa5519c3a5.png)
