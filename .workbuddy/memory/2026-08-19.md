## 售后工单：VLAR-20-15-M2-24-BV 回零堵转 → -1 回零方式反向距离设 0
- 客户现象："z轴使能断了都不在0位，回零老堵转"
- 型号 VLAR-20-15-M2-24-BV = 音圈电机 ZR 一体（退市在役），M2 磁栅
- 根因：客户用 -1 回零方式，反向距离参数设 0 → 碰挡板后反向走 0 距离停在挡板位 → 大电流堵转
- 解决：反向距离改 1000 脉冲，碰挡板后反向走 1000 离开挡板到待机位，回零完成
- 关键知识（C038）：-1 = 碰挡板后反向走固定脉冲距离（≠ -3 碰挡板反向找 Z 脉冲）；-1 不依赖 Z 脉冲/原点开关，光栅/磁栅通用
- 我之前误判"M2 磁栅不能用 -1 应改 19"，Fly 纠正；已同步 corrections C038、控制卡样本回零表、faq-直驱/电缸、新建案例-005、案例库索引、index（53页）
