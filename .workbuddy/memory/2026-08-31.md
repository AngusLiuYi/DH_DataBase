## 手册版本升级投喂：PGIA.PGEA 操作手册 V3.3 → V3.4

- Fly 投喂新版 PDF 并要求比对版本差异。手册 37 页 → 38 页。
- **比对方法（可复用）**：pdfplumber 逐页提取 → 归一化（去所有空白、去页眉页脚、去纯数字页码行）→
  先按页首行锚点对齐、定位插入页 → SequenceMatcher 逐页 get_opcodes 输出 [增/删/改]。
  脚本 `build/diff/extract.py`，产物 `extracted.json` / `v33.txt` / `v34.txt` / `diff_clean.txt`。
  关键点：**必须去掉所有空白再比对**，否则整页都是排版噪音，看不到实质差异。
- **实质差异只有 2 处**：
  1. 🔴 0x0200 初始化状态反馈取值 1：V3.3「处于初始化过程」（笔误）→ V3.4「初始化完成」。
     现场影响：按 V3.3 写的上位机会把"完成"误判为"进行中"，表现为一直等初始化不发指令。
  2. 🟢 新增推压段 4 个寄存器：0x010C 推压段总长度(0-1000,默认0) / 0x010D 推压力(1-100,默认20) /
     0x010E 推压速度(1-100,默认20) / 0x010F 推压方向(0闭合/1张开)。
- **重要发现（防踩坑）**：电爪推压段地址 0x010C-0x010F 与电缸推压段地址
  （0x0102 长度 / 0x0101 推压力 / 0x0309 推压速度 / 0x030A 推压方向）**完全不通用**，别互搬。
  PGHL/PGLS 走电缸方案（C037），推压段同电缸。
- V3.4 手册本身不完整：推压段只在 P13 总览表，无正文详解 / 无目录条目 / 无示例帧；
  P15 正文表 2.4 的 0x0200 仍是旧写法；目录页码未随溢出页更新。已列 5 个待研发确认问题。
- 产出：`build/diff/PGIA-PGEA操作手册_V3.3-vs-V3.4_差异报告.md`；
  更新 `wiki/manual-dh-pgia-pgea-电爪操作手册.md`、`wiki/manual-dh-485寄存器表总览.md`（新增推压段三方对照表）；
