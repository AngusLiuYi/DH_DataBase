## 技术约定（wiki 编译口径）

### 推压段寄存器：电缸与电爪地址不通用（2026-08-31 确认）
- **电缸**（MCEA 等）：0x0102 推压段长度(0.01mm) / 0x0101 推压力 / 0x0309 推压速度 / 0x030A 推压方向(0正/1反/2双向)
- **PGIA/PGEA 电爪**（V3.4 起）：**0x010C** 推压段总长度(0-1000‰,默认0) / **0x010D** 推压力(1-100,默认20) /
  **0x010E** 推压速度(1-100,默认20) / **0x010F** 推压方向(0闭合/1张开，无双向)
- **PGHL/PGLS 走电缸方案**（C037），推压段同电缸，且支持 0x1600 控制字；其他电爪不支持控制字。
- 客户报"推压段设了没反应 / 写不进去"→ 先确认是电缸还是电爪，地址不同。

### 手册版本升级比对工作流
- 流程：pdfplumber 逐页提取 → **去所有空白**归一化 + 去页眉/纯数字页码行 → 按页首行锚点对齐定位插入页 →
  SequenceMatcher 逐页 get_opcodes 输出 [增/删/改]。
- 关键：**不去掉空白的话整页都是排版噪音**，实质差异会被淹没。
- MANIFEST 处理：新版本登「已编译」，旧版本标「已归档（被 VX.X 取代）」，不要删行。
